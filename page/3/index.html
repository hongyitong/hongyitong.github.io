术语表

A

ABS 参见资产支持证券（Asset-Backed Security）。
ABS CDO 由不同资产支持证券（ABS）的分层（tranches）构建的证券。
应计利息（Accrued Interest） 自上一次付息日以来，债券所累积的利息。
附加第一类资本（Additional Tier 1 Capital） 如非累积优先股等不符合第一类股权资本资格的项目。
附加因子（Add-On Factor） 在计算衍生品交易的等价信用量时，为考虑未来衍生品价值可能的变动，在当前敞口基础上所增加的一定比例的本金。
联合差分（Adjoint Differentiation） 修改计算机程序的一种方法，使其能够以高效方式计算希腊字母（即金融风险指标）。
高级计量法（Advanced Measurement Approach） 在巴塞尔协议Ⅱ中，大多数管理成熟的银行被允许用于操作风险监管资本计算的方法。
逆向选择（Adverse Selection） 一种现象，如果保险公司对所有人收取相同的保费，它最终可能主要为高风险人群提供保障。
代理成本（Agency Costs） 当业务关系中的双方利益并不完全一致时所产生的成本。
阿尔法（Alpha） 投资组合获得的超出资本资产定价模型（CAPM）所预测的收益部分。
另类投资（Alternative Investments） 参见对冲基金（Hedge Funds）。
美式期权（American Option） 可以在其整个有效期内任何时间行权的期权。
解析结果（Analytic Result） 解以公式形式表达的结果。
套利（Arbitrage） 一种利用两个或多个证券之间相对定价错误的交易策略。
套利定价理论（Arbitrage Pricing Theory） 一种理论，认为投资回报取决于多个因素。

套利者（Arbitrageur） 从事套利活动的个人。
ASF因子（ASF Factor） 可用稳定资金因子（Available Stable Funding Factor），在计算净稳定资金比率（NSFR）时用于资金来源的一种权重因子。
亚式期权（Asian Option） 其收益取决于标的资产在特定期间内平均价格的期权。
卖出价（Ask Price） 做市商（dealer）愿意出售某项资产的价格，也称offer price。
索要价（Asked Price） 参见卖出价（Ask Price）。
资产互换（Asset Swap） 将债券承诺支付的票息交换为LIBOR加点差的一种交易。
资产支持证券（Asset-Backed Security） 由债券、抵押贷款、信用卡应收账款或其他工具产生的现金流构建的证券。
平值期权（At-the-Money Option） 行权价等于标的资产当前价格的期权。
自相关（Autocorrelation） 某一变量与其在k天后取值之间的相关性（k称为时间滞后）。
均价看涨期权（Average Price Call Option） 收益为零与资产平均价格超过行权价的差值之间较大者的期权。
均价看跌期权（Average Price Put Option） 收益为零与行权价超过资产平均价格的差值之间较大者的期权。

开始使用

使用软件最困难的部分通常是开始。以下是使用RMFI软件进行期权估值的逐步指南。

  1. 打开您已下载的Excel文件 RMFI Software v1.00。
  2. 如果您使用的是Office 2007，请点击屏幕顶部（F列上方）的Options，然后点击Enable content。如果您使用的不是Office 2007，确保您的宏安全设置为中等或低。 (您可以通过点击Tools，然后是Macros，再点击Security来设置)。
  3. 点击页面底部的Equity_FX_Indx_Fut_Opts_Calc工作表标签。
  4. 选择Currency作为标的类型，选择Binomial: American作为期权类型，然后点击Put按钮。保持Imply Volatility未勾选。
  5. 现在，您已经准备好计算一个美式看跌期权的价格了。需要输入七个参数：汇率、波动率、无风险利率（本国）、外币无风险利率、到期时间（年）、行权价格和时间步数。将这些参数输入到以下单元格中：D5、D6、D7、D8、D13、D14、D15，具体数值为：1.61、12%、8%、9%、1.0、1.60 和 4。
  6. 按下键盘上的Enter键并点击Calculate。您将在D20单元格看到期权的价格为0.07099，希腊字母值显示在D21到D25单元格中。
  7. 点击Display Tree，您将看到用于计算期权的二项树。

《风险管理与金融机构》附录M SIMM（标准初始保证金模型）

发表于 2026-08-13 分类于 书籍翻译

附录 M SIMM

Standard Initial Margin Model 标准初始保证金模型

如第6章所讨论的，部分标准的OTC衍生品交易通过中央对手方（CCPs）进行清算，而一些交易仍然通过双边清算。监管机构要求对于双边清算的交易，必须提交初始保证金和变动保证金。变动保证金要求对未清算交易的估值达成一致，并已制定程序以解决任何有关估值的分歧。初始保证金的计算比交易估值更为复杂，且不同模型可能会得出不同的结果。因此，业界曾尝试制定一个行业标准。

初始保证金在监管规定中被指定为两方之间未清算交易的组合的10天内的价值增益，我们有99%的把握它不会在市场压力情况下被超越。需要注意的是，初始保证金是VaR的镜像。当我们计算VaR时，我们是在确定损失分布的极端百分位数，而当我们计算初始保证金时，我们是在确定收益分布的极端百分位数。这是因为随着未抵押组合价值的增加，风险敞口也随之增加。

巴塞尔委员会提出了一种网格方法来计算初始保证金，该方法将初始保证金规定为不同类型交易的名义本金的百分比。然而，这种方法不受欢迎，因为它没有考虑净额对冲的因素。如果市场参与者在第1天进行某个交易，并在第5天与相同的对手方几乎完全对冲的交易，尽管与对手方的净敞口接近零，第5天的初始保证金几乎是第1天的两倍。为了解决这个问题，国际衍生品市场协会（ISDA）提出了所谓的标准初始保证金模型（SIMM）。该模型现在已获得监管机构的批准。

附录 L 合成CDO及其估值

Synthetic CDOs and Their Valuation

合成担保债务义务（CDO）由不同的级别组成，其中一方（Party A）同意向另一方（Party B）支付等同于特定债务工具组合在某一范围内发生的损失的款项。作为回报，Party B 同意向 Party A 支付一部分被保险本金的金额。

假设某个级别的损失范围从 \(\alpha_L\) 到 \(\alpha_H\)。其中，变量 \(\alpha_L\) 和 \(\alpha_H\) 分别被称为附着点和脱离点。如果 \(\alpha_L = 8\%\) 且 \(\alpha_H = 18\%\)，Party A 向 Party B 支付在该债务组合中，损失发生时位于 8% 到 18% 之间的部分。因此，组合的前 8% 损失不会影响该级别。该级别负责承担接下来的 10% 损失（其名义本金最初为 18% - 8% = 10% 的组合本金），随着损失的发生，名义本金逐渐减少。当损失超过 18% 时，该级别被完全清除。Party B 向 Party A 支付的款项是定期支付的，按照适用于剩余名义本金的指定利率进行。这一指定利率被称为该级别的利差（tranche spread）。

附录 I 主成分分析

Principal Components Analysis

主成分分析（PCA）旨在理解相关变量数据的结构。该分析的目的是通过较少数量的无关变量来替代原有的 \(n\) 个变量。在第14.3节的例子中，有8个变量，分别是1年期、2年期、3年期、4年期、5年期、7年期、10年期和30年期互换利率的日变化。

分析的第一步是从数据中计算协方差矩阵。如第9.3节所述，这个矩阵是一个 \(n \times n\) 的矩阵，其中（i，j）位置的元素是变量 \(i\) 和变量 \(j\) 之间的协方差。对角线上的元素（即 \(i = j\)）是方差。

下一步是计算这个矩阵的特征值和特征向量（见附录 H）。特征向量被选定为长度为1的向量。（如附录 H 中所述，这意味着特征向量元素的平方和等于1。）对应最大特征值的特征向量是第一个主成分；对应第二大特征值的特征向量是第二个主成分，依此类推。在第14.3节的例子中的主成分如表14.3所示。

第 \(i\) 个主成分的特征值占所有特征值总和的百分比，表示第 \(i\) 个主成分解释的总体方差的百分比。第 \(i\) 个特征值的平方根是第 \(i\) 个因子得分的标准差（见表14.4）。

《风险管理与金融机构》附录H 特征向量和特征值

发表于 2026-08-08 分类于 书籍翻译

附录 H 特征向量和特征值

Eigenvectors and Eigenvalues

考虑一个 \(n \times n\) 矩阵 \(A\)，假设 \(x\) 是一个 \(n \times 1\) 向量。考虑方程：

\[ A x = \lambda x \tag{H.1} \]

该方程可以写成：

\[ (A - \lambda I) x = 0 \]

其中 \(I\) 是 \(n \times n\) 单位矩阵（即对角线元素为1，其他元素为0的矩阵）。显然，\(x = 0\) 是方程 (H.1) 的一个解。那么，在什么情况下会有其他解呢？线性代数中的定理告诉我们，当 \(A - \lambda I\) 的行列式为零时，方程 (H.1) 存在其他解。换句话说，得到方程 (H.1) 解的 \(\lambda\) 值是当我们解方程 \(\det(A - \lambda I) = 0\) 时得到的。这是一个关于 \(\lambda\) 的 \(n\) 次多项式方程。一般来说，它有 \(n\) 个解。这些解就是矩阵 \(A\) 的特征值。对于每个特征值，解方程 (H.1) 的向量 \(x\) 是特征向量。一般来说，矩阵 \(A\) 有 \(n\) 个特征向量，每个特征向量对应一个特征值。

发表于 2026-08-07 分类于 书籍翻译

附录G 泰勒级数展开

Taylor Series Expansions

考虑一个函数 \(z = F(x)\)。当对 \(x\) 进行一个小的变化 \(\Delta x\) 时，\(z\) 会发生相应的小变化 \(\Delta z\)。\(\Delta z\) 与 \(\Delta x\) 之间的关系的一个近似是：

\[ \Delta z = \frac{dz}{dx}\Delta x \tag{G.1} \]

当 \(z\) 是 \(x\) 的线性函数时，这个关系是准确的，在其他情况下则是近似的。

一个更精确的近似为：

\[ \Delta z = \frac{dz}{dx}\Delta x + \frac{1}{2} \frac{d^2z}{dx^2} (\Delta x)^2 \tag{G.2} \]

当 \(z\) 是 \(x\) 的二次函数时，这个关系是准确的，在其他情况下则是近似的。通过在级数中加入更多项，我们可以提高精度。完全展开式为：

\[ \Delta z =\frac{dz}{dx} \Delta x + \frac{1}{2!} \frac{d^2z}{dx^2} (\Delta x)^2 + \frac{1}{3!} \frac{d^3z}{dx^3} (\Delta x)^3 + \frac{1}{4!} \frac{d^4z}{dx^4} (\Delta x)^4 + \cdots \]

其中，\(!\) 表示阶乘函数：\(2! = 2 \times 1 = 2\)；\(3! = 3 \times 2 \times 1 = 6\)；\(4! = 4 \times 3 \times 2 \times 1 = 24\)；以此类推。

Scoring and iteratively improving model responses

本章涵盖

  • 用简单的基于规则的评分器对 LLM 答案进行评分
  • 计算 LLM 对其答案的置信度
  • 编写一个自我改进循环，其中 LLM 迭代改进其答案

This chapter covers

  • Scoring LLM answers with a simple rule-based scorer

  • Computing an LLM’s confidence in its answers

  • Coding a self-refinement loop where the LLM iteratively improves its answers

前一章介绍了推理时间缩放（简称推理缩放）的概念，即在不进一步训练的情况下提高模型响应的准确性。具体来说，它重点介绍了自一致性，即模型生成多个答案，最终答案选择出现最频繁的那个。

如图 5.1 所示，本章将超越自一致性推理缩放，涵盖另一种流行且有用的推理缩放技术——自我改进（self-refinement)。与生成多个答案并从中选择不同，自我改进侧重于迭代改进单个答案，以纠正潜在的错误。

评分和迭代改进模型响应 本章涵盖无需模型训练即可改进推理的技术。
前一章重点 扩展文本生成函数并实现基于投票的技术以提高答案准确性。
本章介绍 一种模型迭代改进自己答案的推理时间缩放技术。

图 5.1 本书涵盖主题的模型图。 本章继续阶段 3，重点放在无需额外训练即可改进推理的推理时间技术上。它引入了自我改进，即模型迭代地批评和改进自己的答案。

第 3 章 评估推理模型

Evaluating reasoning models

本章涵盖

  • 从 LLM 响应中可靠地提取最终答案
  • 通过将 LLM 的输出与参考解决方案进行比较，使用符号数学求解器验证答案的正确性
  • 运行一个完整的评估流水线，加载预训练模型，生成输出，并对照数据集进行评分

This chapter covers

  • Extracting final answers reliably from an LLM response

  • Verifying answer correctness by comparing an LLM’s output to the reference solution using a symbolic math solver

  • Running a full evaluation pipeline that loads a pretrained model, generates outputs, and grades them against a dataset

评估是我们区分那些仅仅听起来有说服力的 LLM 和那些能够正确解决问题的 LLM 的方法。LLM 评估技术涵盖了广泛的方法，从衡量任务准确性到确保 LLM 遵守特定的安全标准。在本章中，"评估"意味着在大量样本上定量测试模型，并将其输出与参考答案进行评分。

更具体地说，我们将重点实现一种基于验证的方法，通过使用类似计算器的实现，将 LLM 的答案与参考解决方案进行比较，从而检查 LLM 是否能准确解决数学问题。

这种验证器特别有用，因为它不仅评估了数学任务上的性能，还引入了可验证奖励（verifiable rewards）的原则，这是我们在第 6 章中将要实现的强化学习方法的基础。

《Build_a_Reasoning_Model》第1章理解推理模型

第 1 章 理解推理模型

Understanding reasoning models

本章涵盖

  • 对大型语言模型而言，"推理"意味着什么
  • 回顾 LLM 的传统预训练和后训练阶段
  • 介绍提升 LLM 推理能力的关键方法
  • 推理与模式匹配有何不同
  • 为什么我们应该从头构建推理模型

This chapter covers - What “reasoning” means for a large language model - Reviewing the conventional pretraining and post-training stages of LLMs - Introducing key approaches to improving reasoning abilities in LLMs - How reasoning differs from pattern matching - Why we should build reasoning models from scratch

欢迎来到大型语言模型（LLM）的下一个阶段：推理。LLM 已经改变了我们处理和生成文本的方式，但它们的成功很大程度上是由统计模式识别驱动的。推理方法的新进展现在使 LLM 能够处理更复杂的任务，例如解决逻辑谜题和多步数学问题。

此外，推理是使 AI 智能体变得实用的关键技术——例如当智能体需要将任务分解为步骤、使用工具并从错误中恢复时。推理 LLM 已经应用于像 OpenClaw 这样的智能体应用中。

在本书中，你将通过动手实践、代码优先的方法学习 LLM 推理方法的内在运作方式。我们将从一个预训练的 LLM 出发，逐步为其扩展推理能力。我们将从零开始亲自实现这些推理组件，以了解这些方法在实践中如何工作。

如果你对 LLM 本身是如何构建和训练的感到好奇，我之前由 Manning 出版的著作《Build a Large Language Model (From Scratch)》(http://mng.bz/orYv) 详细介绍了这些基础，但并非跟随本书的先决条件。

即使你只是粗略了解 LLM 的构建方式，到本书结束时，你也会理解推理模型的工作原理，并能够设计、原型化和评估改进 LLM 推理的主要方法。

在处理推理模型时，关键是要知道如何在数学等任务上自动检查答案是否正确，以及如何将通用模型转化为更小的推理模型。我们将在全书中使用数学示例，因为它们易于自动检查，但你不需要高级数学知识来跟随学习。理解推理方法是本书的核心重点。

本书以实际应用和解释为重点，面向 LLM 工程师、机器学习研究人员、应用科学家和软件开发者。理解推理模型的设置方式将帮助我们判断何时标准 LLM 已足够，何时额外的推理机制值得增加的复杂性、成本和延迟。它还帮助我们设计更好的评估、调试多步任务中的失败，并将推理技术适配到实际产品和研究工作流中。

《Build_a_Reasoning_Model》前言

发表于 2026-09-06 分类于 书籍翻译

前言

十余年前，我踏入人工智能领域的旅程始于统计模式分类——在那里，我了解到相对简单的模型在捕捉数据中的有用结构时可以走多远。随着时间的推移，我的好奇心从识别模式的模型转向了能够解释、规划和解决多步问题的模型。

随着 2022 年 ChatGPT 的发布，大型语言模型（LLM）进入了主流视野。随后的一次转变——尤其在 2024 年末和 2025 年全年尤为显著——是将 LLM 扩展为所谓的推理模型，这类模型能够解决更复杂的问题，特别是在数学和代码等技术领域。

与此同时，推理模型有时让人感觉难以捉摸，而本书正是我为了让推理模型更加平易近人所做的一次尝试。我们不会从头训练一个巨型模型，而是从一个较小的预训练 LLM 出发，一步一步地应用推理技术。在此过程中，你将亲手实现文本生成、使用验证器进行评估、推理时缩放方法，以及诸如基于可验证奖励的强化学习和知识蒸馏等训练方法。到本书结束时，你将理解主要的推理方法在实践中如何运作，以及它们如何融入现代 LLM 开发工作流。

与我之前的著作《Build a Large Language Model (From Scratch)》一样，本书采用代码优先的方法，但侧重点有所不同。本书不会深入讲解 Transformer 架构或大规模预训练，而是聚焦于将传统 LLM 转化为推理模型的方法。如果你读过我之前的那本书，本书会像是一个自然的下一个阶段。如果没有读过，你仍然可以跟随本书的节奏，无需事先掌握所有底层 LLM 的细节。

我们将在全书中使用数学示例，因为它们既适合推理研究实践，又便于自动验证。这使得它们成为判断模型是否真正正确解决问题的有效测试平台。更广泛地说，我的目标不是讲授某一个狭窄的基准，而是为你提供构建、评估和改进推理系统所需的工具和直觉——无论在你自己的工作中还是其他地方。

当我最初开始研究推理模型时，我不得不从论文、代码仓库和零散的实现笔记中拼凑各种想法。我希望本书能够为你省去这些麻烦，为你提供一条从基本原理到可运行代码的更清晰的路径。我坚信，理解推理模型的最佳方式就是亲手构建一个。

祝阅读和编码愉快！

关于跑步

发表于 2026-09-03 分类于 随笔

前段时间因为天气热，跑步出汗太多，听从了老中医的说法，出汗太多导致身体虚，就改成了快走。

不过，不知道是心理作用还是真的有效果，快走的微出汗，感觉身体确实好了一些，打喷嚏、流鼻涕的现象倒是少了很多。

不过，等天凉了，还是开始跑步吧，跑步出一身汗的那种感觉还是快走代替不了的。

说起跑步，广义上从高中三年算起，已经20多年了，狭义上从2013年算起，也十多年了。算是坚持了一辈子的运动。

我们那个年代的高中，压力山大，特别是我们这些市里面最好的尖子班的学生。那个年代没有所谓的心理健康教育，学校和家长都没这方面的意识和知识，一切都是自己扛。

为了克服学业带来的压力，跑步成了最好的释放点。记得那时候还是晨跑，每天5点半起床，跑上2公里，整个人一天都从好心情开始。那时候操场跑道还是那种煤渣铺的，如果是现在肯定是不符合环保标准的，不过那个年代是一个没有质疑的时代，包括质疑精神和知识储备。印象最深刻的是，每次最后的100米，都是以100米的速度快速冲刺。当时的想法，是锻炼自己的意志力。

还记得，有一年校运会，作为一个非体育生，报名了1500米的比赛，好像是拿了第5名的样子，作为一个成绩尖子生，这也算是人生的唯一一个体育的项目奖项吧。在比赛最后100米，跑道边同班同学的加油声，至今仍在耳边回响。

如果说高中的晨跑是为了释放学业压力，那2013年的夜跑就是为了应对职场的压力而开始。

那一年，曾经的好领导调走了，来了新领导。真的应验了什么是一朝天子一朝臣，各种牛鬼蛇神迅速上位，而我们这些老臣子自然是打压清洗的对象。

回想那段时间，确实是自己顺利职场中的第一次挫折。

不过，杀不死你的只会让你强大！

就是这段时间里，自己奋发图强，开始看了好多的技术和职场的书，自己不断的充实和加强自己。

为了应对压力，也开始了夜跑。

夜跑的事情还得感谢潘石屹，那时候他是名人，他经常分享跑步的动态。

自己自然的有样学样开始了夜跑，在体育中心一跑就是13年。

还记得，为了让自己坚持下去，自己在微信朋友圈发Flag，坚持21天的习惯养成打卡。不知道那时候亲朋好友们对此会不会甚是反感；)

习惯就这样坚持了下来，自己的身体也感觉好了很多，陈年的鼻炎也好了很多。

其中一件花絮就是，当时给自己的目标是，如果新领导在任超过两年，自己就换工作，巧合的是，快到两年的时候，他真的离任了。还记得那年的年会上是我两年来最开心的一次，第一次喝了尽兴酒，可见当时的压抑程度。不过，还是感谢这个领导，俗话说，生于忧患，死于安乐，那两年的逆境确实让我成长了很多。

后期就是习惯成自然的跑步了，换上跑鞋，跑上10公里，5公里，成了一天最放松的时间。

如今已是天体的夜跑常客了。

在这过程中，也见识了形形色色的人。

有热衷于跑步然后摆拍的小女生，有爱光着膀子的强健的男生，还有那些地中海的大叔，大家都因为跑步这个共同的爱好而遇见。

因为跑步是一种长期的自然的习惯，夜跑爱好者出动的时间基本都是固定的，跑着跑着大家都面熟了，有时候，听到后面的脚步声，都能判断出是哪一位了。

说到跑步，想起了一句话。

选择跑步、读书这类爱好，不是因为它们"更高雅"，而是因为它们的学习成本极低（一双鞋、一本书），且不依赖创意能力——只需要坚持。

关于素质教育和人生感悟

发表于 2026-09-01 分类于 随笔

网上一堆关于素质教育和人生感悟的文章，特别是发自那些占据话语权的所谓成功人士。听起来很有道理，但是于普通人来说，这些心灵鸡汤式的话语，甚于毒药。

以下看到的一篇对所谓心灵鸡汤最有力的反驳，个人觉得很中肯。

关于心灵鸡汤，不同人的人生就像横向树，不同的人在不同的分支路径上，每个人的前置路径和后面的分支都是不同的，所以，在每个节点需要对分支做选择的时候，后面的分支是不同的。例如，有钱人说素质教育，不需要努力学习，但是他们即使成绩好不好，他们后面的分支都是回归到回去家族公司，而普通人，努力，成绩好，后面的分支可能就是人生的跃升，而成绩不好，大概率会跌入底层；例如成功者总是说一些鸡汤的话，那是因为他的人生的前置分支是在成功的基础上，而普通人的分支是在另外一个分支上，如果听了别人的所谓人生忠告，你的人生的分支不一定就是好的结果。
另外，死亡是所有人生分支的汇合点，没有例外，老人，或者说快到生命终点的人，在看到这个节点的时候，总是感叹之前的人生，提出人生的一些忠告，但是，这是忠告只是在面临人生最终归属的时候，把之前的人生分支简化了，或者说，只是考虑到了自己的那条分支而提出的反思。对于普通人来说，这些并不适用，因为你人生后面的分支还有万万千千。

就像有钱人总说钱不重要一样。

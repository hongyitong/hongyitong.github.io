8 语音实验

Speech Experiments

我们进行实验研究一种组合式方法，将语音能力集成到 Llama 3 中，类似于我们用于视觉识别的方法。在输入端，我们引入了一个编码器（encoder）和一个适配器（adapter）来处理语音信号。我们利用系统提示（文本形式）来启用 Llama 3 中语音理解的不同操作模式。如果不提供系统提示，模型将作为通用口语对话模型运行，能够以与纯文本版 Llama 3 一致的方式有效回应用户的语音。对话历史作为提示前缀引入，以改善多轮对话体验。我们还实验了使用系统提示来启用 Llama 3 的自动语音识别（ASR）和自动语音翻译（AST）功能。Llama 3 的语音接口支持多达 34 种语言。它还允许文本和语音的交错输入，使模型能够解决高级音频理解任务。

我们还实验了一种语音生成方法，其中我们实现了一个流式文本到语音（TTS）系统，在语言模型解码过程中实时生成语音波形。我们基于专有的 TTS 系统为 Llama 3 设计语音生成器，并且不对语言模型进行语音生成的微调。相反，我们专注于通过在推理时利用 Llama 3 嵌入来改善语音合成的延迟、准确性和自然度。语音接口如图 28 和图 29 所示。

8.1 数据

Data

8.1.1 语音理解

Speech Understanding

训练数据可分为两类。预训练数据包含大量未标注的语音，用于以自监督方式初始化语音编码器。有监督微调数据包括语音识别、语音翻译和口语对话数据；这些数据在与大语言模型集成时用于解锁特定能力。

预训练数据。 为了预训练语音编码器，我们整理了一个约 1500 万小时的语音录音数据集，涵盖大量语言。我们使用语音活动检测（VAD）模型过滤音频数据，并选择 VAD 阈值高于 0.7 的音频样本进行预训练。在语音预训练数据中，我们还重点确保不包含个人身份信息（PII）。我们使用 Presidio Analyzer 来识别此类 PII。

语音识别和翻译数据。 我们的 ASR 训练数据包含 23 万小时的人工转录语音录音，涵盖 34 种语言。我们的 AST 训练数据包含 9 万小时的翻译数据，涵盖两个方向：从 33 种语言到英语，以及从英语到 33 种语言。这些数据包含有监督数据和使用 NLLB 工具包生成的合成数据。使用合成 AST 数据使我们能够提高低资源语言的模型质量。我们数据中的语音片段最大长度为 60 秒。

口语对话数据。 为了微调用于口语对话的语音适配器，我们通过让语言模型响应这些提示的转录来合成生成回复。我们使用 ASR 数据集的子集（6 万小时语音）以这种方式生成合成数据。此外，我们还通过在用于微调 Llama 3 的数据子集上运行 Voicebox TTS 系统，生成了 2.5 万小时的合成数据。我们使用了几种启发式方法来选择与语音分布相匹配的微调数据子集。这些启发式方法包括关注相对较短的提示、结构简单且不含非文本符号的提示。

8.1.2 语音生成

Speech Generation

语音生成数据集主要包括用于训练文本规范化（TN）模型和韵律模型（PM）的数据。两个训练数据都通过添加 Llama 3 嵌入的额外输入特征来增强，以提供上下文信息。

文本规范化数据。 我们的 TN 训练数据集包括 55K 个样本，涵盖广泛需要非平凡规范化的符号类别（例如数字、日期、时间）。每个样本是一对书面形式文本和相应的规范化口语形式文本，并附有执行规范化的手工 TN 规则推断序列。

韵律模型数据。 PM 训练数据包括从 50K 小时 TTS 数据集中提取的语言学和韵律特征，这些数据是专业配音演员在录音室环境中录制的配对转录文本和音频。

Llama 3 嵌入。 Llama 3 嵌入取自第 16 层解码器的输出。我们专门使用 Llama 3 8B 模型，并为给定文本（即 TN 的书面形式输入文本或 PM 的音频转录文本）提取嵌入，就好像它们是由 Llama 3 模型在空用户提示下生成的一样。在给定样本中，Llama 3 令牌序列中的每个块都明确与 TN 或 PM 的本机输入序列中的对应块对齐，即 TN 特定的文本令牌（按 Unicode 类别划分）或音素率特征。这使得 TN 和 PM 模块能够以 Llama 3 令牌和嵌入的流式输入进行训练。

8.2 模型架构

Model Architecture

8.2.1 语音理解

Speech Understanding

在输入端，语音模块由两个连续的模块组成：一个语音编码器和一个适配器。语音模块的输出直接作为令牌表示输入到语言模型中，从而实现语音和文本令牌之间的直接交互。此外，我们引入了两个新的特殊令牌来包裹语音表示序列。语音模块与视觉模块有显著不同（见第 7 节），视觉模块通过交叉注意力层将多模态信息输入到语言模型中。相比之下，语音模块生成的嵌入可以无缝地与文本令牌集成，使语音接口能够利用 Llama 3 语言模型的所有能力。

语音编码器。 我们的语音编码器是一个具有 1B 参数的 Conformer 模型。模型的输入由 80 维的梅尔频谱图特征组成，这些特征首先经过一个步长为 4 的堆叠层，随后通过线性投影将帧长度减少到 40 毫秒。生成的特征由具有 24 层 Conformer 层的编码器处理。每个 Conformer 层的潜在维度为 1536，包含两个维度为 4096 的 Macron-net 风格前馈网络、一个核大小为 7 的卷积模块，以及一个具有 24 个注意力头的旋转注意力模块。

语音适配器。 语音适配器包含约 100M 参数。它由一个卷积层、一个旋转 Transformer 层和一个线性层组成。卷积层核大小为 3，步长为 2，设计用于将语音帧长度减少到 80 毫秒。这使得模型能够向语言模型提供更粗粒度的特征。Transformer 层的潜在维度为 3072，前馈网络维度为 4096，在卷积降采样后进一步处理来自语音的上下文信息。最后，线性层将输出维度映射到与语言模型嵌入层相匹配的维度。

8.2.2 语音生成

Speech Generation

我们在语音生成的两个关键组件中使用 Llama 3 8B 嵌入：文本规范化和韵律建模。TN 模块通过根据上下文将书面文本转换为口语形式来确保语义正确性。PM 模块通过使用这些嵌入预测韵律特征来增强自然度和表现力。它们共同实现了准确且自然的语音生成。

文本规范化。 作为生成语音语义正确性的决定因素，文本规范化（TN）模块执行从书面形式文本到相应口语形式的上下文感知转换，最终由下游组件进行发音。例如，书面形式文本 123 根据语义上下文可以读作基数词（one hundred twenty three）或逐位拼读（one two three）。TN 系统由一个基于 LSTM 的流式序列标注模型组成，该模型预测用于转换输入文本的手工 TN 规则序列。神经模型还通过交叉注意力接收 Llama 3 嵌入，以利用其中编码的上下文信息，从而实现最小的文本令牌前瞻和流式输入/输出。

韵律建模。 为了增强合成语音的自然度和表现力，我们集成了一个仅解码器 Transformer 架构的韵律模型（PM），该模型将 Llama 3 嵌入作为额外输入。这种集成利用了 Llama 3 的语言能力，利用其文本输出和令牌级别的中间嵌入来增强韵律特征的预测，从而减少模型所需的前瞻。

PM 集成多个输入组件以生成全面的韵律预测：来自上述文本规范化前端的语言特征、令牌和嵌入。PM 预测三个关键的韵律特征：每个音素的 log 时长、log F0（基频）平均值和 log 功率在音素时长上的平均值。该模型由一个单向 Transformer 和六个注意力头组成。每个块包括交叉注意力层和隐藏维度为 864 的双全连接层。PM 的一个独特之处在于其双交叉注意力机制，一层专门处理语言输入，另一层处理 Llama 嵌入。这种设置有效地管理不同的输入速率，无需显式对齐。

8.3 训练方案

Training Recipe

8.3.1 语音理解

Speech Understanding

语音模块的训练分为两个阶段。第一阶段，语音预训练，利用未标注数据训练一个在跨语言和跨声学条件下具有强大泛化能力的语音编码器。第二阶段，有监督微调，将适配器和预训练编码器与语言模型集成，并与语言模型联合训练，同时保持 LLM 冻结。这使得模型能够响应语音输入。该阶段使用对应于语音理解能力的标注数据。

多语言 ASR 和 AST 建模常常导致语言混淆/干扰，从而降低性能。缓解此问题的一种流行方法是引入语言识别（LID）信息，包括源端和目标端。这可以在预定的翻译方向上提高性能，但也会带来潜在的泛化能力损失。例如，如果翻译系统期望在源端和目标端都有 LID，那么模型在训练中未见过的方向上不太可能表现出良好的零样本性能。因此，我们的挑战是设计一个系统，在允许一定程度的 LID 信息的同时，保持模型的通用性，使其能够在未见过的方向上进行语音翻译。为解决这一问题，我们设计了系统提示，其中仅包含要输出的文本（目标端）的 LID 信息。这些提示中不包含语音输入（源端）的 LID 信息，这也可能使其能够处理语码混合的语音。对于 ASR，我们使用以下系统提示：请用{语言}重复：，其中{语言}来自 34 种语言之一（英语、法语等）。对于语音翻译，系统提示为：将以下句子翻译成{语言}：。这种设计已被证明能有效提示语言模型以期望的语言进行回复。我们在训练和推理时使用相同的系统提示。

语音预训练。 我们使用自监督 BEST-RQ 算法对语音编码器进行预训练。我们对输入的梅尔频谱图应用长度为 32 帧、概率为 2.5% 的掩码。如果语音话语长度超过 60 秒，我们随机裁剪 6K 帧，对应 60 秒的语音。我们通过堆叠 4 个连续帧、将 320 维向量投影到 16 维空间，并在 8,192 个向量的码本中基于余弦相似度度量进行最近邻搜索来量化梅尔频谱图特征。为稳定预训练，我们使用 16 个不同的码本。投影矩阵和码本随机初始化，在整个模型训练过程中不更新。出于效率考虑，仅对掩码帧使用多 softmax 损失。编码器训练 500K 步，全局批大小为 2,048 个话语。

有监督微调。 预训练的语音编码器和随机初始化的适配器在监督微调阶段与 Llama 3 进一步联合优化。语言模型在此过程中保持不变。训练数据是 ASR、AST 和口语对话数据的混合。Llama 3 8B 的语音模型训练了 650K 个更新步，全局批大小为 512 个话语，初始学习率为 10⁻⁴。Llama 3 70B 的语音模型训练了 600K 个更新步，全局批大小为 768 个话语，初始学习率为 4 × 10⁻⁵。

8.3.2 语音生成

Speech Generation

为支持实时处理，韵律模型采用了一种前瞻机制，考虑固定数量的未来音素和可变数量的未来令牌。这确保了在处理输入文本时保持一致的前瞻，这对于低延迟语音合成应用至关重要。

训练。 我们开发了一种利用因果掩码的动态对齐策略，以促进语音合成的流式处理能力。该策略结合了针对固定数量未来音素和可变数量未来令牌的前瞻机制，与文本规范化过程中的分块处理保持一致。对于每个音素，令牌前瞻包括由块大小定义的最大令牌数，导致 Llama 嵌入的前瞻可变，而音素的前瞻固定。

Llama 3 嵌入来自 Llama 3 8B 模型，该模型在韵律模型训练期间保持冻结。输入的音素率特征包括语言和说话人/风格可控性元素。模型训练的批大小为 1,024 个话语，每个话语最长 500 个音素。我们使用学习率 9 × 10⁻⁴ 的 AdamW 优化器，训练超过 100 万个更新步，前 3,000 步进行学习率预热，之后遵循余弦调度。

推理。 在推理过程中，采用相同的前瞻机制和因果掩码策略，以确保训练和实时处理之间的一致性。PM 以流式方式处理传入文本，逐音素更新音素率特征输入，逐块更新令牌率特征。新的块输入仅在当前块的第一个音素为当前处理位置时更新，保持与训练时相同的对齐和前瞻。

对于韵律目标预测，我们采用延迟模式方法，该方法增强了模型捕获和再现长程韵律依赖的能力。这种方法有助于合成语音的自然度和表现力，确保低延迟和高质量的输出。

8.4 语音理解结果

Speech Understanding Results

我们在三个任务上评估 Llama 3 语音接口的语音理解能力：（1）自动语音识别，（2）语音翻译，以及（3）口语问答。我们将 Llama 3 语音接口的性能与三种最先进的语音理解模型进行比较：Whisper、SeamlessM4T 和 Gemini。在所有评估中，我们使用贪心搜索进行 Llama 3 令牌预测。

语音识别。 我们在多语言 LibriSpeech（MLS）、LibriSpeech、VoxPopuli 的英文数据集以及多语言 FLEURS 数据集的一个子集上评估 ASR 性能。在评估中，解码结果使用 Whisper 文本规范化器进行后处理，以确保与报告的其他模型结果比较的一致性。在所有基准测试中，我们测量了 Llama 3 语音接口在这些基准测试标准测试集上的词错误率，但对于中文、日文、韩文和泰文，报告的是字符错误率。

安全性。 我们在 MuTox 上评估了语音模型的安全性，MuTox 是一个多语言音频数据集，包含 20,000 个英语和西班牙语话语以及 4,000 个其他 19 种语言的话语，每个话语都带有毒性标签。将音频作为模型输入，评估输出的毒性，在清理一些特殊字符后进行。我们应用 MuTox 分类器并将结果与 Gemini 1.5 Pro 进行比较。我们评估了当输入提示安全而输出有毒时的毒性增加（AT）百分比，以及当输入提示有毒而回答安全时的毒性丢失（LT）百分比。表 33 显示了英语和所有评估的 21 种语言的平均结果。毒性增加的百分比非常低：我们的语音模型在英语上毒性增加百分比最低，低于 1%。它消除的毒性远多于增加的毒性。

8.5 语音生成结果

Speech Generation Results

对于语音生成，我们专注于评估使用 Llama 3 嵌入的逐令牌流式输入模型在文本规范化和韵律建模任务上的质量。评估侧重于与未将 Llama 3 嵌入作为额外输入的模型进行比较。

文本规范化。 为了衡量 Llama 3 嵌入的效果，我们实验改变了模型使用的右侧上下文数量。我们使用 3 个 TN 令牌（按 Unicode 类别划分）的右侧上下文训练模型。将此模型与不使用 Llama 3 嵌入、使用 3 个令牌右侧上下文或完全双向上下文训练的模型进行比较。如表 34 所示，使用完整右侧上下文提高了不使用 Llama 3 嵌入的模型的性能。然而，结合了 Llama 3 嵌入的模型优于所有其他模型，从而实现了令牌率输入/输出流式处理，而无需依赖输入中的长上下文。

韵律建模。 为评估我们的韵律模型（PM）与 Llama 3 8B 的性能，我们进行了两轮人工评估，比较有和没有 Llama 3 嵌入的模型。评估人员聆听来自不同模型的样本并指出他们的偏好。为生成最终的语音波形，我们使用内部的基于 Transformer 的声学模型预测频谱特征，并使用 WaveRNN 神经声码器生成最终的语音波形。

首先，我们直接与一个不含 Llama 3 嵌入的流式基线模型进行比较。在第二项测试中，将 Llama 3 8B 韵律模型（PM）与一个不含 Llama 3 嵌入的非流式基线模型进行比较。如表 35 所示，相比流式基线，Llama 3 8B PM 有 60% 的概率更受偏好；相比非流式基线，这一比例为 63.6%，表明感知质量有显著提升。Llama 3 8B PM 的关键优势在于其逐 token 的流式能力（见第 8.2.2 节），这能在推理过程中保持低延迟。这降低了模型的前瞻（lookahead）需求，从而相比非流式基线实现更灵敏、更实时的语音合成。总体而言，Llama 3 8B 韵律模型始终优于基线模型，证明了它在提升合成语音自然度和表现力方面的有效性。

《The Llama 3 Herd of Models》引言

发表于 2026-10-04 分类于 书籍翻译

1 引言

Introduction

Llama 3 模型群组

Llama Team, AI @ Meta¹

¹详细的贡献者名单见本文附录。

现代人工智能（AI）系统由基础模型驱动。本文介绍一组新的基础模型，称为 Llama 3。这是一个原生支持多语言、编码、推理和工具使用的语言模型群组。我们最大的模型是一个稠密 Transformer，拥有 405B 参数和最高 128K token 的上下文窗口。本文对 Llama 3 进行了广泛的实证评估。我们发现 Llama 3 在众多任务上提供了与 GPT-4 等领先语言模型相当的质量。我们公开发布了 Llama 3，包括预训练和后训练版本的 405B 参数语言模型，以及用于输入和输出安全的 Llama Guard 3 模型。本文还展示了通过组合方法将图像、视频和语音能力集成到 Llama 3 中的实验结果。我们观察到，这种方法在图像、视频和语音识别任务上与当前最优水平具有竞争力。这些模型仍在开发中，尚未广泛发布。

日期：2024 年 7 月 23 日

网站：https://llama.meta.com/

基础模型是为支撑多种 AI 任务而设计的语言、视觉、语音和/或其他模态的通用模型。它们是许多现代 AI 系统的基础。

现代基础模型的开发包括两个主要阶段：（1）预训练阶段，在此阶段模型以大规模方式使用简单的任务（如下一个词预测或图像描述）进行训练；（2）后训练阶段，在此阶段模型被调整为遵循指令、与人类偏好对齐，并提升特定能力（例如编码和推理）。

在本文中，我们介绍一组新的语言基础模型，称为 Llama 3。Llama 3 模型群组原生支持多语言、编码、推理和工具使用。我们最大的模型是一个稠密 Transformer，拥有 405B 参数，上下文窗口最高可处理 128K token。每个模型成员列于表 1 中。本文中呈现的所有结果均为 Llama 3.1 模型的结果，为简洁起见，我们在全文中将其统称为 Llama 3。

¹Llama 3 8B 和 70B 是在多语言数据上预训练的，但当时仅面向英语使用。

表 1 Llama 3 模型群组概览。本文中所有结果均为 Llama 3.1 模型的结果。

我们认为，开发高质量基础模型有三个关键杠杆：数据、规模和复杂性管理。我们在开发过程中力求优化这三个杠杆：

  • 数据。与先前版本的 Llama（Touvron 等，2023a,b）相比，我们改进了用于预训练和后训练的数据的数量和质量。这些改进包括开发更精细的预训练数据预处理和筛选流程，以及开发更严格的后训练数据质量保证和过滤方法。我们在约 15T 多语言 token 的语料上预训练 Llama 3，而 Llama 2 仅为 1.8T token。

  • 规模。我们训练的模型规模远超之前的 Llama 模型：我们的旗舰语言模型预训练使用了 3.8 × 10²⁵ FLOPs，几乎是 Llama 2 最大版本的 50 倍。具体来说，我们在 15.6T 文本 token 上预训练了一个拥有 405B 可训练参数的旗舰模型。正如基础模型缩放定律所预期的那样，我们的旗舰模型优于使用相同流程训练的较小模型。虽然我们的缩放定律表明，在我们的训练预算下，旗舰模型大约达到计算最优规模，但我们同时也将较小的模型训练了远超过计算最优的时间。由此产生的模型在相同推理预算下表现优于计算最优模型。我们在后训练阶段利用旗舰模型进一步提升这些较小模型的质量。

  • 复杂性管理。我们做出的设计选择力求最大化模型开发过程的扩展能力。例如，我们选择标准的稠密 Transformer 模型架构（Vaswani 等，2017）并进行少量调整，而非混合专家模型（Shazeer 等，2017），以最大化训练稳定性。类似地，我们采用了相对简单的基于监督微调（SFT）、拒绝采样（RS）和直接偏好优化（DPO；Rafailov 等，2023）的后训练流程，而非更复杂的强化学习算法（Ouyang 等，2022；Schulman 等，2017），后者往往不够稳定且更难扩展。

我们工作的成果是 Llama 3：一个包含 8B、70B 和 405B 参数三种多语言¹语言模型的群组。我们在涵盖广泛语言理解任务的大量基准数据集上评估了 Llama 3 的性能。此外，我们还进行了广泛的人工评估，将 Llama 3 与竞争模型进行对比。旗舰 Llama 3 模型在关键基准上的表现概览见表 2。我们的实验评估表明，旗舰模型在多种任务上的表现与 GPT-4（OpenAI，2023a）等领先语言模型持平，接近当前最优水平。我们的较小模型在同类别中表现最佳，优于具有相似参数数量的其他模型（Bai 等，2023；Jiang 等，2023）。Llama 3 在有用性和无害性之间的平衡也比其前代（Touvron 等，2023b）好得多。我们在第 5.4 节中对 Llama 3 的安全性进行了详细分析。

我们公开发布所有三个 Llama 3 模型，依据 Llama 3 社区许可证的更新版本；详见 https://llama.meta.com。这包括预训练和后训练版本的 405B 参数语言模型，以及用于输入和输出安全的新版 Llama Guard 模型（Inan 等，2023）。我们希望旗舰模型的开源发布将激发研究社区的创新浪潮，并加速走向通用人工智能（AGI）发展的负责任之路。

作为 Llama 3 开发过程的一部分，我们还开发了模型的多模态扩展，支持图像识别、视频识别和语音理解能力。这些模型仍在积极开发中，尚未准备好发布。除语言建模结果外，本文还展示了我们针对这些多模态模型的初步实验结果。

2 总体概述

General Overview

Llama 3 的模型架构如图 1 所示。我们的 Llama 3 语言模型的开发包括两个主要阶段：

  • 语言模型预训练。我们首先将大型多语言文本语料转换为离散 token，然后在所得数据上预训练大型语言模型（LLM）以执行下一个 token 预测。在语言模型预训练阶段，模型学习语言结构，并从其"阅读"的文本中获取大量关于世界的知识。为了有效完成这一过程，预训练以大规模方式进行：我们在 15.6T token 上使用 8K token 的上下文窗口预训练了一个 405B 参数的模型。这一标准预训练阶段之后是一个持续预训练阶段，将支持的上下文窗口扩展到 128K token。详见第 3 节。

  • 语言模型后训练。预训练语言模型对语言有深入的理解，但它尚未能遵循指令或以我们期望的助手方式行事。我们通过多轮人类反馈对齐模型，每轮涉及对指令微调数据进行监督微调（SFT）和直接偏好优化（DPO；Rafailov 等，2024）。在此后训练²阶段，我们还集成了新能力，如工具使用，并在编码和推理等其他领域观察到了显著的改进。详见第 4 节。最后，在后训练阶段也将安全缓解措施融入模型，具体细节在第 5.4 节中描述。

由此产生的模型具有丰富的能力。它们可以至少用八种语言回答问题、编写高质量代码、解决复杂推理问题，并以开箱即用或零样本方式使用工具。

我们还进行了实验，使用组合方法将图像、视频和语音能力添加到 Llama 3 中。我们研究的该方法包括图 28 中所示的三个额外阶段：

  • 多模态编码器预训练。我们为图像和语音分别训练了独立的编码器。我们在大量图像-文本对上训练图像编码器。这教会了模型视觉内容与自然语言描述之间的关系。我们的语音编码器采用自监督方法进行训练，该方法掩码掉语音输入的部分内容，并尝试通过离散令牌表示重建被掩码的部分。因此，模型学习了语音信号的结构。关于图像编码器的详细信息见第 7 节，关于语音编码器的详细信息见第 8 节。

  • 视觉适配器训练。我们训练一个适配器，将预训练的图像编码器集成到预训练的语言模型中。该适配器由一系列交叉注意力层组成，将图像编码器的表示输入到语言模型中。适配器在图像-文本对上进行训练。这使图像表示与语言表示对齐。在适配器训练期间，我们还更新图像编码器的参数，但有意不更新语言模型的参数。我们还在图像适配器之上，在配对的视频-文本数据上训练一个视频适配器。这使得模型能够跨帧聚合信息。详见第 7 节。

  • 语音适配器训练。最后，我们通过一个适配器将语音编码器集成到模型中，该适配器将语音编码转换为可以直接输入到微调语言模型的令牌表示。适配器和编码器的参数在监督微调阶段联合更新，以实现高质量的语音理解。在语音适配器训练期间，我们不改变语言模型。我们还集成了一个文本到语音系统。详见第 8 节。

我们的多模态实验产生了能够识别图像和视频内容，并支持通过语音界面进行交互的模型。这些模型仍在开发中，尚未准备好发布。

²在本文中，我们使用术语"后训练"指代预训练之外的所有模型训练。

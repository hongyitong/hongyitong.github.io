《风险管理与金融机构》附录F 美式期权的估值

发表于 2026-08-06 分类于 书籍翻译

附录F 美式期权的估值

Valuing American Options

为了估值美式期权，我们将期权的生命周期分成 \(n\) 个时间步长，每个时间步长的长度为 \(\Delta t\)。假设在一个时间步长的开始时，资产价格为 \(S\)。在时间步长结束时，资产价格以概率 \(p\) 上涨至 \(S_u\)，以概率 \(1 - p\) 下跌至 \(S_d\)。对于不产生收益的投资资产，\(u\)、\(d\) 和 \(p\) 的值由以下公式给出： \[ u = e^{\sigma \sqrt{\Delta t}}, \quad d = \frac{1}{u}, \quad p = \frac{a-d}{u - d} \]

其中，

\[ a = e^{r \Delta t} \]

这里，\(r\) 是无风险利率，\(\sigma\) 是资产的波动率。

图F.1展示了一个用于估值五个月期美式看跌期权的树状图，标的资产为不支付股息的股票，初始股价为50，执行价格为50，无风险利率为10%，波动率为40%。在这个例子中，时间步长为五个步骤，因此 \(\Delta t = 0.08333\)，\(u = 1.1224\)，\(d = 0.8909\)，\(a = 1.0084\)，\(p = 0.5073\)。每个节点上方的数字是股价，下方的数字是期权的价值。

在树的最终节点，期权价格为其内在价值。例如，在节点G处，期权的价格为 \(50 - 35.36 = 14.64\)。在较早的节点，我们首先计算期权如果再持有一个时间步长 \(\Delta t\) 的价值，然后检查是否早期行权是最优的。

首先考虑节点E。如果期权再持有一个时间步长，它的价值将是：如果上涨（概率为 \(p\)），则为 \(0.00\)，如果下跌（概率为 \(1 - p\)），则为 \(5.45\)。因此，期望值为：

\[ 0.5073 \times 0 + 0.4927 \times 5.45 = 2.686 \]

节点E的期权价值是通过以10%的无风险利率将这个值折现一个月得到的 \(2.66\)。由于早期行权的收益为零，因此在节点E不应行权。

接下来考虑节点A。类似的计算结果显示，如果期权再持有一个时间步长，其在节点A的价值为 \(9.90\)。如果行权，期权的价值为 \(50 - 39.69 = 10.31\)。在这种情况下，应当行权，因此节点A的期权价值为 \(10.31\)。

继续从树的终端节点向初始节点回溯，期权在初始节点D的价值为4.49。随着树上时间步数的增加，期权价格的准确性也会提高。在30步、50步和100步的情况下，期权的价值分别为4.263、4.272和4.278。

为了计算Delta，我们考虑在时间步长为 \(\Delta t\) 的两个节点。在我们的例子中，从较低节点移动到较高节点时，期权价格从6.96变化为2.16，股票价格从44.55变为56.12。Delta的估算值是期权价格的变化除以股票价格的变化：

\[ \Delta = \frac{2.16 - 6.96}{56.12 - 44.55} = -0.415 \]

为了计算Gamma，我们考虑时间为 \(2\Delta t\) 时的三个节点。由上面两个节点（C和F）计算得到的Delta为 \(-0.241\)，这可以视为股票价格为 \((62.99 + 50) / 2 = 56.49\) 时的Delta。由下方两个节点（B和C）计算得到的Delta为 \(-0.639\)，这可以视为股票价格为 \((50 + 39.69) / 2 = 44.84\) 时的Delta。Gamma的估算值是Delta的变化除以股票价格的变化：

\[ \Gamma = \frac{-0.241 - (-0.639)}{56.49 - 44.84} = 0.034 \]

我们通过节点D和C估算Theta：

\[ \Theta = \frac{3.77 - 4.49}{2 \times 0.08333} = -4.30 \text{ per year} \]

即每年 \(-4.30\)，这相当于每自然日 \(-0.0118\)。

Vega通过增加波动率，构建新的树，并观察波动率增加对期权价格的影响来估算。Rho的计算方法类似。

当标的资产提供收益率 \(q\) 时，计算过程完全相同，只是公式中的 \(a = e^{(r - q) \Delta t}\)，而不是 \(e^{r \Delta t}\)。（当标的资产为外币时，\(q\) 设置为外币的无风险利率。）当期权是基于远期或期货价格时，\(a\) 设置为1，树中的每个节点显示远期或期货价格。

我们所描述的这些计算可以使用RMFI软件完成，该软件可以通过访问作者的网站获得，并选择“Option Type: Binomial American”。二项树和其他数值方法在Hull（2022）中有更详细的描述。

《风险管理与金融机构》附录G 泰勒级数展开

发表于 2026-08-07 分类于 书籍翻译

附录G 泰勒级数展开

Taylor Series Expansions

考虑一个函数 \(z = F(x)\)。当对 \(x\) 进行一个小的变化 \(\Delta x\) 时，\(z\) 会发生相应的小变化 \(\Delta z\)。\(\Delta z\) 与 \(\Delta x\) 之间的关系的一个近似是：

\[ \Delta z = \frac{dz}{dx}\Delta x \tag{G.1} \]

当 \(z\) 是 \(x\) 的线性函数时，这个关系是准确的，在其他情况下则是近似的。

一个更精确的近似为：

\[ \Delta z = \frac{dz}{dx}\Delta x + \frac{1}{2} \frac{d^2z}{dx^2} (\Delta x)^2 \tag{G.2} \]

当 \(z\) 是 \(x\) 的二次函数时，这个关系是准确的，在其他情况下则是近似的。通过在级数中加入更多项，我们可以提高精度。完全展开式为：

\[ \Delta z =\frac{dz}{dx} \Delta x + \frac{1}{2!} \frac{d^2z}{dx^2} (\Delta x)^2 + \frac{1}{3!} \frac{d^3z}{dx^3} (\Delta x)^3 + \frac{1}{4!} \frac{d^4z}{dx^4} (\Delta x)^4 + \cdots \]

其中，\(!\) 表示阶乘函数：\(2! = 2 \times 1 = 2\)；\(3! = 3 \times 2 \times 1 = 6\)；\(4! = 4 \times 3 \times 2 \times 1 = 24\)；以此类推。

示例 G.1

考虑函数 \(z = \sqrt{x}\)，因此：

\[ \frac{dz}{dx} = \frac{1}{2} x^{-1/2} \]

\[ \frac{d^2z}{dx^2} = -\frac{1}{4} x^{-3/2} \]

\[ \frac{d^3z}{dx^3} = \frac{3}{8} x^{-5/2} \]

假设 \(x = 2\) 和 \(\Delta x = 0.1\)，则：

\[ \Delta z = \sqrt{2.1} - \sqrt{2} = 0.034924 \]

当 \(x = 2\) 时，

\[ \frac{dz}{dx} = 0.35355, \quad \frac{d^2z}{dx^2} = -0.08839, \quad \frac{d^3z}{dx^3} = 0.06629 \]

根据公式 (G.1)，一阶近似的 \(\Delta z\) 为：

\[ \Delta z = 0.35355 \times 0.1 = 0.035355 \]

根据公式 (G.2)，二阶近似的 \(\Delta z\) 为：

\[ \Delta z = 0.35355 \times 0.1 + \frac{1}{2} \times (-0.08839) \times 0.1^2 = 0.034913 \]

三阶近似为：

\[ \Delta z = 0.35355 \times 0.1 + \frac{1}{2} \times (-0.08839) \times 0.1^2 + \frac{1}{6} \times 0.06629 \times 0.1^3 = 0.034924 \]

可以看出，级数展开迅速收敛到正确的结果 \(0.034924\)。

G.1 两个变量的函数

Functions of Two Variables

考虑一个两个变量的函数 \(z = F(x, \gamma)\)。假设 \(\Delta x\) 和 \(\Delta \gamma\) 分别是 \(x\) 和 \(\gamma\) 的小变化，且 \(\Delta z\) 是相应的 \(z\) 的小变化。在这种情况下，一阶近似为：

\[ \Delta z= \frac{\partial z}{\partial x} \Delta x + \frac{\partial z}{\partial \gamma} \Delta \gamma \tag{G.3} \]

二阶近似为：

\[ \Delta z = \frac{\partial z}{\partial x} \Delta x + \frac{\partial z}{\partial \gamma} \Delta \gamma + \frac{1}{2} \frac{\partial^2 z}{\partial x^2} (\Delta x)^2 + \frac{1}{2} \frac{\partial^2 z}{\partial \gamma^2} (\Delta \gamma)^2 + \frac{\partial^2 z}{\partial x \partial \gamma} \Delta x \Delta \gamma \tag{G.4} \]

这两个近似给出了小变化 \(\Delta x\) 和 \(\Delta \gamma\) 对函数 \(z\) 变化的影响，二阶近似考虑了更多的高阶导数，提供了更高精度的估算。

示例 G.2

考虑函数 \(z = \sqrt{x\gamma}\)，因此：

\[ \frac{\partial z}{\partial x} = \frac{1}{2} \gamma^{1/2} x^{-1/2}, \quad \frac{\partial z}{\partial \gamma} = \frac{1}{2} x^{1/2} \gamma^{-1/2} \]

\[ \frac{\partial^2 z}{\partial x^2} = -\frac{1}{4} \gamma^{1/2} x^{-3/2}, \quad \frac{\partial^2 z}{\partial \gamma^2} = -\frac{1}{4} x^{1/2} \gamma^{-3/2} \]

\[ \frac{\partial^2 z}{\partial x \partial \gamma} = \frac{1}{4} x^{-1/2} \gamma^{-1/2} \]

假设 \(x = 2\)，\(\gamma = 1\)，\(\Delta x = 0.1\)，\(\Delta \gamma = 0.1\)，则：

\[ \Delta z = \sqrt{2.1 \times 1.1} - \sqrt{2 \times 1} = 0.10565 \]

当 \(x = 2\) 和 \(\gamma = 1\) 时，

\[ \frac{\partial z}{\partial x} = 0.35355, \quad \frac{\partial z}{\partial \gamma} = 0.70711 \]

\[ \frac{\partial^2 z}{\partial x^2} = -0.08839, \quad \frac{\partial^2 z}{\partial \gamma^2} = -0.35355, \quad \frac{\partial^2 z}{\partial x \partial \gamma} = 0.17678 \]

根据公式 (G.3)，一阶近似的 \(\Delta z\) 为：

\[ \Delta z = 0.35355 \times 0.1 + 0.70711 \times 0.1 = 0.10607 \]

根据公式 (G.4)，二阶近似的 \(\Delta z\) 为：

\[ \Delta z = 0.35355 \times 0.1 + 0.70711 \times 0.1 + \frac{1}{2} \times (-0.08839) \times (0.1)^2 + \frac{1}{2} \times (-0.35355) \times (0.1)^2 + 0.17678 \times 0.1 \times 0.1 = 0.10562 \]

该级数解已快速收敛到正确答案 \(0.10565\)。

G.2 一般结果

General Result

对于一个有 \(n\) 个变量 \(x_1, x_2, \dots, x_n\) 的函数 \(z\)，泰勒级数给出的二阶近似为：

\[ \Delta z = \sum_{i=1}^{n} \frac{\partial z}{\partial x_i} \Delta x_i + \frac{1}{2} \sum_{i=1}^{n} \sum_{j=1}^{n} \frac{\partial^2 z}{\partial x_i \partial x_j} \Delta x_i \Delta x_j \]

这个公式表示了函数 \(z\) 在多个变量变化下的近似变化，其中包含了一阶和二阶导数对变化的贡献。

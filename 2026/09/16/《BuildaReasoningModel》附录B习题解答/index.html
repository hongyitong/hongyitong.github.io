练习 6.2：零优势（Zero-advantage）情况

如果所有奖励都相等（例如，全部为 0 或全部为 1），则优势（advantages）将全部为 0，因为减去均值后只剩下零，如下所示：

这将返回 tensor([0., 0., 0., 0.])。

类似地，如果将 rollout_rewards 改为 rollout_rewards = [0., 0., 0., 0.]，我们会得到相同的全零张量 tensor([0., 0., 0., 0.])。

简而言之，如果一组中的所有奖励都相同，例如所有奖励都是 0 或所有奖励都是 1，那么 $r_i - \mu_i = 0$ 对于所有 $i$ 个展开结果成立。因此，策略梯度为零，该提示的模型参数不会更新。

这种行为是刻意的。如果所有展开结果都同样差或同样好，就没有相对信号来告诉模型应该强化或抑制哪种行为。直观地说，如果模型正确回答了所有问题，就没有必要更新它。反之，如果模型错误回答了所有问题，我们也不希望更新模型来强化这种行为。

GPT-2（2019）：多头注意力 → LayerNorm 2 → 前馈网络 → LayerNorm 1 + Dropout → Token 嵌入层 → 位置嵌入层 → 分词文本 → 样本输入文本 → 重复 12 次 → 最终 LayerNorm → 线性输出层 → 输出处理步骤 → 样本输出文本

Qwen3（2025）：分组查询注意力 → RMSNorm 2 → 前馈网络 → RMSNorm 1 + → Token 嵌入层 → 位置嵌入层 → 分词文本 → 样本输入文本 → 重复 28 次 → 最终 RMSNorm → 线性输出层 → 输出处理步骤 → 样本输出文本 → RoPE → QKNorm

如果您是 LLM 新手并想了解这些架构是如何实现的，我建议从 GPT-2 开始。其设计更易于实现，这使得它在探索更现代的变体之前是一个更容易的切入点。

C.1 RMSNorm

与使用标准 LayerNorm 的 GPT-2 不同，较新的 Qwen3 架构使用均方根层归一化（RMSNorm），这一趋势在最近的模型架构中越来越普遍。

RMSNorm 实现与 LayerNorm 相同的核心功能：对层激活进行归一化以稳定和改进训练。但它简化了计算，去掉了均值中心化步骤，如图 C.2 所示。这意味着激活仍然被归一化，但不再以零为中心。

操作 输入值 均值 方差 输出值 输出均值 输出方差
LayerNorm [5.61, 14.32, 0.00, 34.88, 38.70, 11.29, 2.09, -9.72, -7.55, 3.24, -1.09] 17.47 207.91 [-0.82, -0.22, -1.21, 1.21, 1.47, -0.43, …] 0.00 1.00
RMSNorm [5.61, 14.32, 0.00, 34.88, 38.70, 11.29, 2.09, -9.72, -7.55, 3.24, -1.09] 17.47 207.91 [0.25, 0.63, 0.00, 1.54, 1.71, 0.50, …] 0.77 0.41

图 C.2 LayerNorm（GPT-2 使用）与 RMSNorm（Qwen3 使用）的比较。LayerNorm（右侧）对激活进行归一化，使其均值恰好为零，方差恰好为一。RMSNorm（左侧）根据均方根缩放激活，不强制零均值或单位方差，但仍然将均值和方差保持在合理范围内，以实现稳定训练。

如图 C.2 所示，LayerNorm 和 RMSNorm 都将层输出缩放到合理的范围。

LayerNorm 减去均值并除以标准差，使层输出具有零均值和单位方差（方差为一，标准差为一），从而产生有利于稳定训练的梯度性质。

RMSNorm 将输入除以均方根。这可以将激活缩放到可比较的幅度，而不强制零均值或单位方差。在图 C.2 所示的示例中，均值为 0.77，方差为 0.41。

LayerNorm 和 RMSNorm 都能稳定激活规模并改善优化，但 RMSNorm 在大规模 LLM 中通常更受青睐，因为它计算成本更低。与 LayerNorm 不同，RMSNorm 默认不使用偏置（偏移）项，这减少了可训练参数的数量。此外，RMSNorm 将昂贵的均值和方差计算简化为单一的均方根操作。这使跨特征规约从两次减少到一次，降低了 GPU 上的通信开销，并略微提高了训练效率。

C.2 前馈模块

前馈模块（一个小型多层感知机）被替换为 2020 年一篇论文《GLU Variants Improve Transformer》（https://arxiv.org/abs/2002.05202）中引入的门控线性单元（GLU）变体。在这种设计中，标准的两个全连接层被替换为三个，如图 C.3 所示。

GPT-2（2019）：线性层 1 → 激活函数 → 线性层 2

Qwen3（2025）：线性层 1 → 激活函数 + 线性层 2 → 两者相乘 → 线性层 3

图 C.3 在 GPT-2（上方）中，前馈模块由两个全连接（线性）层组成，中间由一个非线性激活函数分隔。在 Qwen3（下方）中，该模块是一种门控线性单元（GLU）变体，增加了第三个线性层（线性层 3），并将其输出与线性层 1 的激活输出逐元素相乘。

图 C.3 中所示的 Qwen3 前馈模块可以实现如下：

清单 C.2 Qwen3 的前馈模块

乍一看，Qwen3 使用的 GLU 前馈变体似乎应该优于 GPT-2 中的标准前馈变体，仅仅因为它增加了一个线性层（三个而不是两个），因此看起来有更多参数。

但这种直觉是有误导性的。GLU 变体中的 fc1 和 fc2 层各只有标准前馈模块中 fc1 层宽度的一半，因此 GLU 变体的参数反而更少。

为了用具体例子说明，假设图 C.3 中线性层 1 的输入维度为 1024。这对应于清单 C.2 中的 cfg["emb_dim"]。fc1 的输出维度为 3072（cfg["hidden_dim"]）。这些是 Qwen3 0.6B 变体中使用的实际数字。在这种情况下，清单 C.2 中 GLU 变体的参数数量如下：

  • fc1: 1024 × 3072 = 3,145,728
  • fc2: 1024 × 3072 = 3,145,728
  • fc3: 3072 × 1024 = 3,145,728
  • 总计: 3 × 3,145,728 = 9,437,184 个参数

如果假设该 GLU 变体中 fc1 的宽度是标准前馈模块中 fc1 典型宽度的一半，那么标准前馈模块的参数数量如下：

  • fc1: 1024 × (2 × 3072) = 6,291,456
  • fc2: (2 × 3072) × 1024 = 6,291,456
  • 总计: 2 × 6,291,456 = 12,582,912 个参数

虽然 GLU 变体通常比常规前馈模块参数更少，但它们的性能更好。改进来自门控机制引入的额外乘法交互 activation(x_fc1) * x_fc2，这增加了模型的表达能力。这类似于更窄但更深的网络可以胜过更宽但更浅的网络（在适当训练的情况下）。

在进入下一节之前，还有一点需要说明。请注意，图 C.3 所示的前馈模块中包含一个标有"激活函数"的元素，但我们在清单 C.2 中使用了 nn.functional.silu 激活作为具体示例。

历史上，激活函数一直是争论的热点话题，直到深度学习界在十多年前大致收敛于修正线性单元（ReLU）。ReLU 简单且计算成本低，但它在零处有一个尖锐的拐点。这促使研究人员探索更平滑的函数，如高斯误差线性单元（GELU）和 Sigmoid 线性单元（SiLU），如图 C.4 所示。

图 C.4 可在前馈模块（神经网络）中使用的不同激活函数。GELU 和 SiLU（Swish）提供了 ReLU 的平滑替代方案，ReLU 在输入为零时具有尖锐的拐点。

GELU 涉及高斯累积分布函数（CDF）。计算这个 CDF 比较慢，因为它使用分段逻辑和指数运算，这使得编写融合的、优化的 GPU 内核变得困难，尽管使用 tanh 近似可以使用更便宜的操作并以几乎相同的结果运行更快。简而言之，虽然 GELU 产生平滑的激活曲线，但总体计算成本比简单函数更高。

较新的模型大多将 GELU 替换为 SiLU（也称为 Swish）函数，该函数将大的负输入平滑地抑制到接近 ~0，而对于大的正输入则近似线性，如图 C.4 所示。

SiLU 具有相似的平滑度，但计算成本略低于 GELU，并提供可比的建模性能。在实践中，SiLU 现在用于大多数架构，而 GELU 仅在一些模型中使用，例如 Google 的 Gemma 开源权重 LLM。在清单 C.2 的前馈模块实现中，SiLU 函数通过 nn.functional.silu 调用。清单 C.2 中的前馈模块也常被称为 SwiGLU，这个缩写来自 Swish 和 GLU 两个术语。

C.3 旋转位置嵌入（RoPE）

在基于 Transformer 的 LLM 中，由于注意力机制的性质，位置编码是必要的。默认情况下，注意力将输入的 token 视为没有顺序。在原始的 GPT 架构中，绝对位置嵌入通过为序列中的每个位置添加一个可学习的嵌入向量来解决这个问题，然后将其加到 token 嵌入上。

RoPE（旋转位置嵌入的缩写）使用不同的方法：它不是将位置信息作为单独的嵌入添加，而是通过以依赖于每个 token 位置的方式旋转注意力机制中的查询和键向量来编码位置信息（注意力机制将在下一节讨论）。RoPE 是一个优雅的想法，但其本身就是一个庞大的话题。如果您有兴趣，可以在原始的 RoPE 论文《RoFormer: Enhanced Transformer with Rotary Position Embedding》（https://arxiv.org/abs/2104.09864）中找到更多信息。（RoPE 于 2021 年首次提出，并在 2023 年随着原始 Llama 模型的发布被广泛采用。此后它已成为现代 LLM 的标准配置，并非 Qwen3 独有。）

RoPE 可以通过两种数学上等价的方式实现：交错形式，将相邻维度配对进行旋转；或两半形式，将维度分成余弦和正弦两半以方便处理。以下清单实现了两半变体，更易于阅读。

RoPE 实现变体

如果您熟悉原始的 RoPE 论文（https://arxiv.org/abs/2104.09864），您可能想知道我选择了哪种特定的实现。实现 RoPE 有两种常见风格，它们在数学上是等价的。这些实现主要在旋转矩阵如何配对维度上有所不同。我选择了两半拆分风格，因为它更容易阅读和实现。

1）两半拆分风格（本书、Hugging Face Transformers）：
$$
[x0 ; x1 ; x2 x3 ; x4 ; x5 ; x6 ; x7]
$$

$$
[\cos ; \cos ; \cos ; \cos ; \sin ; \sin ; \sin ; \sin]
$$
旋转矩阵为：
$$
\begin{bmaix}
\cos\eta & -\sin\theta & 0 & 0 & \cdots \
\sin\theta & \cos\theta & 0 & 0 & \cdots \
0 & 0 & \cos\theta & -\sin\theta & \cdots \
0 & 0 & \sin\theta & \cos\theta & \cdots
\end{bmatrix}
$$
这里，嵌入维度被分成两半，每半按块旋转。

2）来始论文（以及官方 Llama 代码库）的交错（偶/奇）RoPE 风格如下：
$$
[x0 ; x1 ; x2 ; x3 ; ; x5 ; x6 ; x7]
$$

$$
[\cos ; \sin ; \cos ; \sin ; \cos ; \sin ; \cos ; \sin]
$$
旋转矩阵为：
$$
\begin{bmatrix}
\cotheta & -in\theta & 0 & 0 & \cdots \
\sin\theta & \cos\theta & 0 & 0 & \cdots \
0 & 0 & \cos\theta & -\sin\theta & \cdots \
0 & 0 & \sin\theta & \cos\theta & \cdots
\end{bmatrix}
$$
这里，嵌入维度以偶/奇余弦/正弦对的方式交错排列。

两种布局编码相同的相对位置。唯一的区别在于维度如何配对。

C.4 分组查询注意力（GQA）

分组查询注意力（GQA）已成为原始多头注意力（MHA）机制的标准替代方案，在计算和参数量方面更高效。与 MHA（每个头拥有自己的一套键和值）不同，GQA 通过将多个头分组共享相同的键和值投影来减少内存使用，如图 C.5 所示。

MHA（多头注意力） GQA（分组查询注意力）
查询: q, q, q, q 查询: q, q, q, q
键: k, k, k, k 键: k, k（共享）
值: v, v, v, v 值: v, v（共享）
头 1-4 各有独立 K/V 头 1-4 共享相同的 K/V 头

图 C.5 MHA 与 GQA 的比较。此处分组大小为 2，意味着一个键-值对由 2 个查询共享。

GQA 的核心思想是通过跨多个查询头共享键和值头来减少其数量。这既降低了模型的参数数量，也减少了推理过程中键和值张量的内存带宽使用，因为需要存储和从 KV 缓存（在 C.7 节讨论）中检索的键和值更少。

虽然 GQA 主要是针对 MHA 的计算效率变通方案，但原始 GQA 论文《GQA: Training Generalized Multi-Query Transformer Models from Multi-Head Checkpoints》（https://arxiv.org/abs/2305.13245）中呈现的消融研究表明，它在 LLM 建模性能方面与标准 MHA 表现相当。

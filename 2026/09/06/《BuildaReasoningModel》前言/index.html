《Build_a_Reasoning_Model》前言

发表于 2026-09-06 分类于 书籍翻译

前言

十余年前，我踏入人工智能领域的旅程始于统计模式分类——在那里，我了解到相对简单的模型在捕捉数据中的有用结构时可以走多远。随着时间的推移，我的好奇心从识别模式的模型转向了能够解释、规划和解决多步问题的模型。

随着 2022 年 ChatGPT 的发布，大型语言模型（LLM）进入了主流视野。随后的一次转变——尤其在 2024 年末和 2025 年全年尤为显著——是将 LLM 扩展为所谓的推理模型，这类模型能够解决更复杂的问题，特别是在数学和代码等技术领域。

与此同时，推理模型有时让人感觉难以捉摸，而本书正是我为了让推理模型更加平易近人所做的一次尝试。我们不会从头训练一个巨型模型，而是从一个较小的预训练 LLM 出发，一步一步地应用推理技术。在此过程中，你将亲手实现文本生成、使用验证器进行评估、推理时缩放方法，以及诸如基于可验证奖励的强化学习和知识蒸馏等训练方法。到本书结束时，你将理解主要的推理方法在实践中如何运作，以及它们如何融入现代 LLM 开发工作流。

与我之前的著作《Build a Large Language Model (From Scratch)》一样，本书采用代码优先的方法，但侧重点有所不同。本书不会深入讲解 Transformer 架构或大规模预训练，而是聚焦于将传统 LLM 转化为推理模型的方法。如果你读过我之前的那本书，本书会像是一个自然的下一个阶段。如果没有读过，你仍然可以跟随本书的节奏，无需事先掌握所有底层 LLM 的细节。

我们将在全书中使用数学示例，因为它们既适合推理研究实践，又便于自动验证。这使得它们成为判断模型是否真正正确解决问题的有效测试平台。更广泛地说，我的目标不是讲授某一个狭窄的基准，而是为你提供构建、评估和改进推理系统所需的工具和直觉——无论在你自己的工作中还是其他地方。

当我最初开始研究推理模型时，我不得不从论文、代码仓库和零散的实现笔记中拼凑各种想法。我希望本书能够为你省去这些麻烦，为你提供一条从基本原理到可运行代码的更清晰的路径。我坚信，理解推理模型的最佳方式就是亲手构建一个。

祝阅读和编码愉快！

关于本书

《Build a Reasoning Model (From Scratch)》是一本实践指南，通过亲手实现核心技术来理解现代推理 LLM 的工作原理。本书不是从头开始训练基础模型，而是**从一个预训练的开源基础 LLM 出发，逐步向你展示如何为其扩展推理能力。**在此过程中，你将学习如何使用基础模型生成文本、使用验证器评估答案、通过推理时缩放提升性能、使用强化学习进行训练，以及将推理行为蒸馏到更小的模型中。到本书结束时，你将理解主要的推理方法如何在实用的 LLM 开发工作流中协同工作，以及如何构建你自己的小型但功能完备的推理系统。

本书采用代码优先的方法。"从零开始"指的是你自己实现推理方法，使底层机制变得透明。如果你对基础 LLM 的构建和预训练细节感兴趣，我之前的著作《Build a Large Language Model (From Scratch)》(http://mng.bz/M96o) 提供了这一基础，但并非阅读本书的先决条件。

读者对象

《Build a Reasoning Model (From Scratch)》面向机器学习爱好者、工程师、研究人员、学生以及软件开发者，他们希望实际理解推理模型的工作原理以及如何实现其背后的主要技术。本书为那些希望超越高层描述、亲眼看到这些系统如何构建、评估和改进的读者而写。

最重要的先决条件是扎实的 Python 经验。有机器学习、深度学习或大型语言模型的先前经验会有帮助，但你不需要成为专家。本书旨在让有动力的初学者也能跟上，同时为经验丰富的实践者提供足够的技术深度。

本书经常使用数学示例，因为它们既适合推理研究实践，又便于自动验证。然而，高级数学知识并非必需。熟悉基础代数和一般的向量及矩阵概念会有所帮助，以便理解部分代码实现。

有一些 PyTorch 的先前经验可能会帮助你更快地阅读代码，但并非必需。本书的重点是理解推理方法并清晰地实现它们，而不是掌握深度学习框架的每一个细节。已经阅读过《Build a Large Language Model (From Scratch)》的读者可能会认出一些更广泛的 LLM 概念，但本书是完全自包含的。

本书的组织方式：路线图

本书围绕推理模型的实用开发流水线来组织。我们将从传统预训练 LLM 开始，添加评估能力以便衡量进展，**然后探索改进推理的两种主要方式：推理时方法和额外训练（inference-time methods and additional training. ）。**由于后面的章节直接建立在前面章节引入的代码和概念之上，建议按顺序阅读。

第 1 章介绍了推理在 LLM 语境中的实际含义。它解释了推理模型与传统 LLM 的区别，在较高层次上回顾了标准的 LLM 训练流水线，并介绍了用于改进推理的主要方法。

第 2 章通过加载和使用预训练的基础 LLM 来建立起点。它涵盖了编码环境、分词、逐步文本生成以及实用的加速技术，如键值缓存和模型代码编译。

第 3 章增加了评估功能。它展示了如何可靠地提取最终答案、如何对照参考答案验证正确性，以及如何为面向数学的推理任务构建评估流水线。

在此基础之上，第 4 章和第 5 章聚焦于推理时缩放——在不改变模型权重的情况下改进推理。第 4 章涵盖基于提示的推理、多样化解码和自洽性。第 5 章将此方向扩展为自我精炼、简单评分策略、置信度估计和迭代答案改进。

第 6 章到第 8 章实现了训练时的方法（training-time methods）。第 6 章介绍了用于推理模型的强化学习，重点是基于可验证奖励的强化学习（RLVR）和组相对策略优化（GRPO）。第 7 章在此基础上涵盖了实际的监控、常见的训练失败模式、奖励黑客行为以及有用的扩展，如 KL 正则化和响应格式奖励。第 8 章以知识蒸馏收尾主体文本，展示了如何创建教师生成的推理数据集、训练更小的学生模型以及评估蒸馏结果。

附录对主体章节进行了补充。附录 A 提供了参考文献和进一步阅读，附录 B 总结了练习解答，附录 C 展示了全书中使用的 Qwen3 源代码，附录 D 讨论了更大的 LLM 变体，附录 E 涵盖了批处理和面向吞吐量的执行，附录 F 概述了额外的 LLM 评估方法，附录 G 展示了如何围绕模型构建聊天界面。

关于代码

为了方便读者跟随学习，本书中的代码示例可从 Manning 图书页面 (https://www.manning.com/books/build-a-reasoning-model-from-scratch) 以及配套的 GitHub 仓库 (https://github.com/rasbt/reasoning-from-scratch) 获取。练习解答总结在附录 B 中，相应的代码文件链接在仓库的章节文件夹中。你还可以从本书的 liveBook（在线）版本获取可执行的代码片段，网址为 https://livebook.manning.com/book/build-a-reasoning-model-from-scratch。

本书包含大量源代码示例，既有编号列表也穿插在正文中。在这两种情况下，源代码都使用等宽字体（如这样）格式化，以区别于普通文本。

在许多情况下，原始源代码已被重新格式化；我们添加了换行符并重新调整了缩进，以适应书中可用的页面空间。此外，当代码在正文中已有描述时，列表中的注释通常已被移除。代码注释伴随着许多列表，强调重要概念。

本书的关键目标之一是易于使用，因此代码示例经过精心设计，可以在普通笔记本电脑上高效运行，无需任何特殊硬件。但如果你确实有 GPU，某些部分会提供有用的提示，帮助你扩展数据集和模型以充分利用额外算力。

主体章节中的代码设计为易读且能在消费级硬件上运行。推理和评估章节在 CPU 和 GPU 上都能良好运行，而训练导向的章节如果你希望重现较大的实验，则最好有 GPU 支持。在整本书中，我们使用 PyTorch 配合预训练的开源 Qwen3 模型，附录 C 提供了底层的 Qwen3 实现，供希望更详细检查该代码的读者参考。

关于封面插图

《Build a Reasoning Model (From Scratch)》封面上的插图题为"La Lionne"（母狮），取自 Louis Curmer 于 1841 年出版的一本书。每幅插图都绘制精细并由手工上色。

在那个年代，仅凭人们的着装就能轻松判断他们居住在哪里以及从事什么行业或社会地位。Manning 以基于几个世纪前丰富多样的地域文化的封面插图来庆祝计算机行业的创造力和进取精神——这些插图通过此类收藏中的图片重新焕发生机。

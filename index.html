前言：

从ChatGPT 2022 年11月 30日面世，这3年多来，手头积累了很多关于AI的资料，包括文章摘录的内容，包括自己的感悟，包括自己使用的感想。

一直想把这些大杂烩整理成一篇文章，但因为头绪太过繁杂，就一直没有动手，最近借着Obsidian的使用，开始着手整理这些。

一开始，把原始的资料发给Gemini整理，Gemini给出了一篇中规中矩的、80分水平的文章，文章只是提炼了资料几个重要的观点，遗漏了大部分信息。

因为原始的资料就像垃圾，俗话说，垃圾进垃圾出。因此还是花了一个上午，好好的把原始资料分门别类的整理了一遍，相当于也把资料的知识过了一遍。把整理后、相对原始的资料发给Gemini，经过以下多轮对话以后，终于成为这篇文章。不过，感觉基本是按照我整理的结构，只是针对我的每段话，加了一些提炼的标题。字数从我原先1.2万多，变成了1.3万。不过总结得还不错，整体结构看起来更规范。

人生旅途

发表于 2026-09-03 分类于 随笔

最近很多杂事，心情也起伏不定，博客也停笔了好多天。

今天是多愁善感的天气，竟然勾引起了书写的情绪。

在AI能力日新月异的时代，个人的文章的实用价值已经不是那么重要了，特别是对于我们这种普通人士。

但AI代替不了人有生以来倾诉、表达的基因冲动，有时候诉诸于面对面的聊天，有时诉诸于笔端。

虽然自己的文字照亮不了世界，至少能照亮自己吧，这也是自己不放弃书写的原因。

今天的秋意渐浓，一早在路上，突然想起一句话。

人生很短，很多人，你其实已经见完最后一面。即便是那些你曾经的好友、亲密爱人。

确实，到了这个年龄，知天命的年纪里。身边的人来来往往，就像公共汽车，有些人注定是要中途下车的，同时又有新的人上车。只是到了如今，下车的人往往多于上车的人了。看着空荡荡的车厢，看着熟悉的位置，你会想起曾经位置上的那个人，仅此而已。

人生的路途，注定是孤独的，属于你的那班车，你需要勇敢的走下去。

关于跑步

发表于 2026-09-03 分类于 随笔

前段时间因为天气热，跑步出汗太多，听从了老中医的说法，出汗太多导致身体虚，就改成了快走。

不过，不知道是心理作用还是真的有效果，快走的微出汗，感觉身体确实好了一些，打喷嚏、流鼻涕的现象倒是少了很多。

不过，等天凉了，还是开始跑步吧，跑步出一身汗的那种感觉还是快走代替不了的。

说起跑步，广义上从高中三年算起，已经20多年了，狭义上从2013年算起，也十多年了。算是坚持了一辈子的运动。

我们那个年代的高中，压力山大，特别是我们这些市里面最好的尖子班的学生。那个年代没有所谓的心理健康教育，学校和家长都没这方面的意识和知识，一切都是自己扛。

为了克服学业带来的压力，跑步成了最好的释放点。记得那时候还是晨跑，每天5点半起床，跑上2公里，整个人一天都从好心情开始。那时候操场跑道还是那种煤渣铺的，如果是现在肯定是不符合环保标准的，不过那个年代是一个没有质疑的时代，包括质疑精神和知识储备。印象最深刻的是，每次最后的100米，都是以100米的速度快速冲刺。当时的想法，是锻炼自己的意志力。

还记得，有一年校运会，作为一个非体育生，报名了1500米的比赛，好像是拿了第5名的样子，作为一个成绩尖子生，这也算是人生的唯一一个体育的项目奖项吧。在比赛最后100米，跑道边同班同学的加油声，至今仍在耳边回响。

如果说高中的晨跑是为了释放学业压力，那2013年的夜跑就是为了应对职场的压力而开始。

那一年，曾经的好领导调走了，来了新领导。真的应验了什么是一朝天子一朝臣，各种牛鬼蛇神迅速上位，而我们这些老臣子自然是打压清洗的对象。

回想那段时间，确实是自己顺利职场中的第一次挫折。

不过，杀不死你的只会让你强大！

就是这段时间里，自己奋发图强，开始看了好多的技术和职场的书，自己不断的充实和加强自己。

为了应对压力，也开始了夜跑。

夜跑的事情还得感谢潘石屹，那时候他是名人，他经常分享跑步的动态。

自己自然的有样学样开始了夜跑，在体育中心一跑就是13年。

还记得，为了让自己坚持下去，自己在微信朋友圈发Flag，坚持21天的习惯养成打卡。不知道那时候亲朋好友们对此会不会甚是反感；)

习惯就这样坚持了下来，自己的身体也感觉好了很多，陈年的鼻炎也好了很多。

其中一件花絮就是，当时给自己的目标是，如果新领导在任超过两年，自己就换工作，巧合的是，快到两年的时候，他真的离任了。还记得那年的年会上是我两年来最开心的一次，第一次喝了尽兴酒，可见当时的压抑程度。不过，还是感谢这个领导，俗话说，生于忧患，死于安乐，那两年的逆境确实让我成长了很多。

后期就是习惯成自然的跑步了，换上跑鞋，跑上10公里，5公里，成了一天最放松的时间。

如今已是天体的夜跑常客了。

在这过程中，也见识了形形色色的人。

有热衷于跑步然后摆拍的小女生，有爱光着膀子的强健的男生，还有那些地中海的大叔，大家都因为跑步这个共同的爱好而遇见。

因为跑步是一种长期的自然的习惯，夜跑爱好者出动的时间基本都是固定的，跑着跑着大家都面熟了，有时候，听到后面的脚步声，都能判断出是哪一位了。

说到跑步，想起了一句话。

选择跑步、读书这类爱好，不是因为它们"更高雅"，而是因为它们的学习成本极低（一双鞋、一本书），且不依赖创意能力——只需要坚持。

网上一堆关于素质教育和人生感悟的文章，特别是发自那些占据话语权的所谓成功人士。听起来很有道理，但是于普通人来说，这些心灵鸡汤式的话语，甚于毒药。

以下看到的一篇对所谓心灵鸡汤最有力的反驳，个人觉得很中肯。

关于心灵鸡汤，不同人的人生就像横向树，不同的人在不同的分支路径上，每个人的前置路径和后面的分支都是不同的，所以，在每个节点需要对分支做选择的时候，后面的分支是不同的。例如，有钱人说素质教育，不需要努力学习，但是他们即使成绩好不好，他们后面的分支都是回归到回去家族公司，而普通人，努力，成绩好，后面的分支可能就是人生的跃升，而成绩不好，大概率会跌入底层；例如成功者总是说一些鸡汤的话，那是因为他的人生的前置分支是在成功的基础上，而普通人的分支是在另外一个分支上，如果听了别人的所谓人生忠告，你的人生的分支不一定就是好的结果。
另外，死亡是所有人生分支的汇合点，没有例外，老人，或者说快到生命终点的人，在看到这个节点的时候，总是感叹之前的人生，提出人生的一些忠告，但是，这是忠告只是在面临人生最终归属的时候，把之前的人生分支简化了，或者说，只是考虑到了自己的那条分支而提出的反思。对于普通人来说，这些并不适用，因为你人生后面的分支还有万万千千。

智能体技能数据驱动分析

发表于 2026-06-23 分类于 书籍翻译

智能体技能（Agent Skills）：关于扩展大语言模型功能的 Claude 技能的数据驱动分析

Agent Skills: A Data-Driven Analysis of Claude Skills for Extending Large Language Model Functionality

数据集： 公开市场 skills.sh 上列出的智能体技能

摘要

Abstract

智能体技能（Agent skills）通过可复用的、类似于程序的模块来扩展大语言模型（LLM）智能体，这些模块定义了触发条件、过程逻辑和工具交互。 随着这些技能在公开市场上的激增，目前尚不清楚有哪些可用的技能类型、用户如何采纳它们以及它们会带来哪些风险。为了回答这些问题，我们对来自一个主要市场的 40,285 个公开上市的技能进行了大规模的数据驱动分析。

我们的研究结果表明，技能的发布往往在短期内爆发式涌现，并与社区关注度的转移相吻合。我们还发现，技能内容高度集中在软件工程工作流中，而信息检索和内容创作在用户采纳中占了很大份额。除了内容趋势外，我们还揭示了各类别之间显著的供需失衡，并且表明尽管长度呈现重尾分布，但大多数技能仍保持在典型的提示词预算（Prompt budgets）之内。最后，我们观察到强大的生态系统同质化，存在广泛的意图级冗余，并识别出了不容忽视的安全风险，包括允许改变状态或系统级操作的技能。

总的来说，我们的研究结果为智能体技能作为一种新兴的智能体基础设施层提供了量化快照，并为未来在技能复用、标准化和安全感知设计方面的研究提供了信息。

Spec-Driven Production Grade Development in the Age of Vibe Coding

在氛围编码（Vibe Coding）时代基于规格说明驱动的生产级开发

可扩展工作流与团队演进蓝图：从氛围原型到生产现实

Vibe Coding" is not “Vibe In Production”

“氛围编码”并非“在生产环境中靠氛围”

引言

Introduction

谷歌软件工程师的日常工作在过去一年中经历了翻天覆地的彻底转变。在 2024 年初及之前，大量时间被耗费在钻研开发者 API 和文档、逐行手动尝试代码，以及确认 Python 使用的是 substring in string、string.includes 还是 string.contains。一旦代码完成，大把的精力又被投入到调试和解决功能代码与原始意图之间的差异上。如今，开发的推进速度快如曲速飞行。团队现在使用 Coding 智能体——如 Antigravity 或 Gemini CLI，它们不仅能推荐文本，还能真正使用工具并执行任务。AI 代码编辑器可以快速吐出上千行文档完备的代码。这感觉就像是雇佣了一支不知疲倦、从不抱怨的实习生大军。但这里有一个陷阱：虽然速度已经冲上云霄，但“速度的幻觉”却是真实存在的。虽然 Bug 与代码的比例仍是一个挑战——因为 AI 编写代码的速度要快得多，它也会以空前的速度生成潜在的错误。然而，由于实现不再是核心瓶颈，我们可以利用 AI 在相同的时间内编写出比任何人类都要更全面的测试覆盖。这是一种强有力的、通过程序化提高代码信心的手段，后文将对此进行详细讨论。此外，AI 的潜力远不止于代码实现：它在系统设计、规格说明书编写、路线图规划以及结果分析方面都表现卓越。尽管瓶颈已经向下游转移到了必须整合并审查这些工作的人类身上，但应对这一挑战的工具现已准备就绪。

“氛围编码（Vibe coding）”是指利用 AI 根据一种“氛围（vibe）”或高层意图来快速生成代码，而不是进行死板的手动编码。然而，必须明确澄清的是，“氛围编码”绝非“在生产环境中靠氛围”。尽管我们发挥了 AI 智能体的全部潜力，但一切都是完全可控且符合预期的，以确保生产级的可靠性，而不是依赖未经校检的 AI 输出。

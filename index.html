《The Llama 3 Herd of Models》8 语音实验

发表于 2026-10-04 分类于 书籍翻译

8 语音实验

Speech Experiments

我们进行实验研究一种组合式方法，将语音能力集成到 Llama 3 中，类似于我们用于视觉识别的方法。在输入端，我们引入了一个编码器（encoder）和一个适配器（adapter）来处理语音信号。我们利用系统提示（文本形式）来启用 Llama 3 中语音理解的不同操作模式。如果不提供系统提示，模型将作为通用口语对话模型运行，能够以与纯文本版 Llama 3 一致的方式有效回应用户的语音。对话历史作为提示前缀引入，以改善多轮对话体验。我们还实验了使用系统提示来启用 Llama 3 的自动语音识别（ASR）和自动语音翻译（AST）功能。Llama 3 的语音接口支持多达 34 种语言。它还允许文本和语音的交错输入，使模型能够解决高级音频理解任务。

我们还实验了一种语音生成方法，其中我们实现了一个流式文本到语音（TTS）系统，在语言模型解码过程中实时生成语音波形。我们基于专有的 TTS 系统为 Llama 3 设计语音生成器，并且不对语言模型进行语音生成的微调。相反，我们专注于通过在推理时利用 Llama 3 嵌入来改善语音合成的延迟、准确性和自然度。语音接口如图 28 和图 29 所示。

7 视觉实验

7 Vision Experiments

我们通过一系列实验，将视觉识别能力以组合方式集成到 Llama 3 中，主要分为两个阶段。首先，我们在一个大规模图像-文本对上，通过在预训练的图像编码器（Xu et al., 2023）和预训练的语言模型之间引入并训练一组交叉注意力层（Alayrac et al., 2022），将两者组合起来，得到如图 28 所示的模型。其次，我们引入时序聚合器层和额外的视频交叉注意力层，在大规模视频-文本对上进行训练，使模型学会识别和处理视频中的时序信息。

《The Llama 3 Herd of Models》6 推理

发表于 2026-10-04 分类于 书籍翻译

6 推理

Inference

我们研究了两种使 Llama 3 405B 模型高效推理的主要技术：（1）流水线并行（pipeline parallelism）和（2）FP8 量化。我们已经公开发布了 FP8 量化的实现。

6.1 流水线并行

Pipeline Parallelism

当使用 BF16 数值表示模型参数时，Llama 3 405B 无法放入单台配备 8 张 Nvidia H100 GPU 的机器中。为了解决这个问题，我们使用 BF16 精度在两台机器的 16 张 GPU 上进行并行模型推理。在每台机器内部，高 NVLink 带宽支持使用张量并行（tensor parallelism）（Shoeybi et al., 2019）。然而，跨节点间的连接带宽较低且延迟较高，因此我们改用流水线并行（pipeline parallelism）（Huang et al., 2019）。

5 结果

Results

我们对 Llama 3 进行了一系列广泛的评估，考察了以下方面的性能：（1）预训练语言模型，（2）后训练语言模型，以及（3）Llama 3 的安全特性。以下各小节分别报告这些评估结果。

5.1 预训练语言模型

Pre-trained Language Model

本节报告我们的预训练 Llama 3（第 3 节）与其他同等规模模型的评估结果对比。在可能的情况下，我们会复现竞争模型的结果。对于非 Llama 模型，我们报告公开可查结果中的最佳得分，或（在可能的情况下）我们自己复现的结果。这些评估的具体细节，包括 few-shot 样本数、指标及其他相关超参数和设置，可在我们的 GitHub 仓库中查看。此外，我们还发布了评估过程中生成的数据，这些数据可在 Huggingface 上获取。我们在标准基准（第 5.1.1 节）上评估模型质量，考察对多项选择题设置变化的鲁棒性（第 5.1.2 节），以及对抗性评估（第 5.1.3 节）。我们还进行了污染分析，以估计训练数据污染对评估结果的影响程度（第 5.1.4 节）。

4 后训练

Post-Training

我们通过对预训练检查点应用多轮后训练³⁶，即让模型与人类反馈对齐（Ouyang et al., 2022; Rafailov et al., 2024），来产生对齐后的 Llama 3 模型。每轮后训练包括监督微调（SFT）以及随后的直接偏好优化（DPO；Rafailov et al., 2024），训练数据来自人工标注或合成生成。我们的后训练建模和数据方法分别在第 4.1 节和第 4.2 节中描述。我们进一步在第 4.3 节中详细介绍了用于提升推理、编程、事实性、多语言、工具使用、长上下文和精准指令遵循能力的定制数据策略。

3 预训练

Pre-Training

语言模型预训练包括：(1) 大规模训练语料的策划与过滤；(2) 模型架构的研发及相应的用于确定模型规模的缩放法则；(3) 大规模高效预训练技术的开发；(4) 预训练方案的制定。下面我们将分别介绍这些组成部分。

3.1 预训练数据

Pre-Training Data

我们通过多种数据来源为语言模型预训练创建数据集，这些数据包含截至 2023 年底的知识。我们对每个数据来源应用多种去重方法和数据清洗机制，以获得高质量的 token。我们移除包含大量个人可识别信息（PII）的域名，以及已知包含成人内容的域名。

Introduction

Llama 3 模型群组

Llama Team, AI @ Meta¹

¹详细的贡献者名单见本文附录。

现代人工智能（AI）系统由基础模型驱动。本文介绍一组新的基础模型，称为 Llama 3。这是一个原生支持多语言、编码、推理和工具使用的语言模型群组。我们最大的模型是一个稠密 Transformer，拥有 405B 参数和最高 128K token 的上下文窗口。本文对 Llama 3 进行了广泛的实证评估。我们发现 Llama 3 在众多任务上提供了与 GPT-4 等领先语言模型相当的质量。我们公开发布了 Llama 3，包括预训练和后训练版本的 405B 参数语言模型，以及用于输入和输出安全的 Llama Guard 3 模型。本文还展示了通过组合方法将图像、视频和语音能力集成到 Llama 3 中的实验结果。我们观察到，这种方法在图像、视频和语音识别任务上与当前最优水平具有竞争力。这些模型仍在开发中，尚未广泛发布。

6.《AI Engineering: Building Applications with Foundation Models》（Chip Huyen）

本书在AI应用或者AI工程的视角上深入浅出地整体介绍了一遍，理论上是AI体系的数学基础、LLM原理之上的应用层面的书籍。不是那么技术，偏科普、偏宏观方面的书，很系统、很全面地介绍了LLM及其应用的一些原理和注意的事项。有点像整个AI软件工程的生命周期：架构设计、评估、安全护栏、成本控制、延迟优化、线上监控等等，偏向于“设计指南”和“架构蓝图”，教读者如何把一个大模型应用真正落地到生产环境。

总体上来说，本书是近期看到的一本很好的介绍大语言模型应用方面的好书，让读者能对整个AI的应用和宏观概念有个系统的理解，非常值得推荐。

普通读者的阅读顺序可以是1-2-6的顺序阅读这几本书。

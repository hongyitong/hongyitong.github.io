前言

大型语言模型（LLM）对世界产生了深远而广泛的影响。通过使机器能够更好地理解和生成类似人类的语言，LLM 在 AI 领域开启了新的可能性，并影响了整个行业。

本书提供了一个全面且高度可视化的 LLM 世界入门介绍，涵盖了概念基础和实际应用。从早于深度学习的词汇表示，到（在撰写本文时）前沿的 Transformer 架构，我们将探索 LLM 的历史和演变。我们深入探讨 LLM 的内部工作原理，探索它们的架构、训练方法和微调技术。我们还将研究 LLM 在文本分类、聚类、主题建模、聊天机器人、搜索引擎等各种应用。

我们希望，凭借其独特的直觉构建、应用和图解风格的结合，本书能为那些希望探索 LLM 激动人心世界的人们提供理想的基础。无论您是初学者还是专家，我们都邀请您加入我们，开始使用 LLM 进行构建。

直觉优先的理念

本书的主要目标是为 LLM 领域提供直觉。语言 AI 领域的发展速度快得令人难以置信，试图跟上最新的技术可能会让人感到沮丧。因此，我们专注于 LLM 的基础知识，并旨在提供一个有趣且轻松的学习过程。

为了实现这种直觉优先的理念，我们大量使用了可视化语言。插图将有助于为 LLM 学习过程中涉及的主要概念和过程提供视觉上的标识。通过我们图解式的叙事方法，我们希望带您踏上这一激动人心、可能改变世界的领域的旅程。

在整本书中，我们明确区分了表征语言模型和生成语言模型。表征模型是不生成文本的 LLM，但通常用于特定任务的用例，例如分类；而生成模型是生成文本的 LLM，例如 GPT 模型。尽管生成模型通常是想到 LLM 时首先想到的，但表征模型仍然有很多用途。我们对大型语言模型中的“大”一词也采取了较为宽泛的使用，并且通常只称它们为语言模型，因为尺寸描述通常相当武断，并不总是能力的指标。

先决条件

本书假设您具有一定的 Python 编程经验，并熟悉机器学习的基础知识。重点将是建立强大的直觉，而不是推导数学方程。因此，插图结合动手实践的例子将贯穿本书的示例和学习过程。

本书假设读者不具备 PyTorch 或 TensorFlow 等流行的深度学习框架的预先知识，也不具备生成建模的任何先验知识。

如果您不熟悉 Python，一个很好的起点是 Learn Python，您可以在其中找到许多关于该语言基础知识的教程。为了进一步简化学习过程，我们已将所有代码上传到 Google Colab，这是一个您无需在本地安装任何东西即可运行所有代码的平台。

书籍结构

本书大致分为三个部分。它们如图 P-1 所示，以便您全面了解本书。请注意，每个章节都可以独立阅读，因此对于您已经熟悉的内容，请随意略读。

第一部分：理解语言模型

在本书的第一部分，我们将探讨语言模型（无论大小）的内部工作原理。我们首先概述该领域和常用技术（参见第 1 章），然后转向这些模型的两个核心组成部分——分词 (tokenization) 和嵌入 (embeddings)（参见第 2 章）。本部分最后将以 Jay 著名的《图解 Transformer》的更新和扩展版本结束，该版本深入探讨了这些模型的架构（参见第 3 章）。本书将介绍贯穿始终的许多术语和定义。

第二部分：使用预训练语言模型

在本书的第二部分，我们将通过常见的用例来探讨如何使用 LLM。我们将使用预训练模型，并在无需微调的情况下展示其功能。

您将学习如何使用语言模型进行有监督分类（参见第 4 章）、文本聚类和主题建模（参见第 5 章）、利用嵌入模型进行语义搜索（参见第 6 章）、生成文本（参见第 7 章和第 8 章），以及将文本生成的能力扩展到视觉领域（参见第 9 章）。

学习这些独立的语言模型功能将为您提供使用 LLM 解决问题和构建越来越高级的系统和流程所需的技能。

第三部分：训练和微调语言模型

在本书的第三部分，我们将通过训练和微调各种语言模型来探索高级概念。我们将探讨如何创建和微调嵌入模型（参见第 10 章），回顾如何微调 BERT 进行分类（参见第 11 章），并以微调生成模型的几种方法结束本书（参见第 12 章）。

硬件和软件要求

运行生成模型通常是一项计算密集型任务，需要配备功能强大的 GPU 的计算机。由于并非所有读者都具备 GPU，本书中的所有示例都设置为使用在线平台运行，即 Google Colaboratory（通常缩写为 Google Colab）。在撰写本文时，该平台允许您免费使用 NVIDIA GPU (T4) 来运行代码。该 GPU 具有 16 GB 的 VRAM（即您的 GPU 内存），这是我们在本书示例中要求的最低 VRAM 量。

并不是所有章节都需要最低 16 GB VRAM，因为有些示例（例如训练和微调）比其他示例（例如提示工程）对计算的要求更高。在代码库中，您可以找到每个章节所需的最低 GPU 要求。

API 密钥

我们在示例中同时使用了开源模型和专有模型，以展示两者的优缺点。对于专有模型，即 OpenAI 和 Cohere 提供的产品，您需要创建一个免费账户：

OpenAI

点击网站上的“注册”（sign up）来创建免费账户。该账户允许您创建一个 API 密钥，可用于访问 GPT-3.5。然后，转到“API 密钥”来创建一个密钥（secret key）。

Cohere

在网站上注册一个免费账户。然后，转到“API 密钥”来创建一个密钥（secret key）。

请注意，这两个账户都有速率限制（rate limits），并且这些免费的 API 密钥只允许每分钟进行有限次数的调用。在所有示例中，我们都考虑了这一点，并在必要时提供了本地替代方案。

对于开源模型，您无需创建账户，第 2 章中的 Llama 2 模型除外。要使用该模型，您需要一个 Hugging Face 账户：

Hugging Face

点击 Hugging Face 网站上的“注册”（sign up）来创建免费账户。然后，在“设置”（Settings）中转到“访问令牌”（Access Tokens），创建一个令牌，您可以使用该令牌下载某些 LLM。
